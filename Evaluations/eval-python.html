02

Entrée & sorties

7 points

Question 1

Expliquez ce qu'est une entrée sortie. Donnez un exemple en Python.
Question 2

Voici les 4 instructions d'un programme, mélangées.

Remetez-les dans l'ordre pour obtenir un dialogue logique :

A. print("Très bien " + prenom + ", bon courage !")
B. nom = input("Quel est ton nom de famille ? ")
C. prenom = input("Bonjour ! Quel est ton prénom ? ")
D. print("Enchanté " + prenom + " " + nom + " !")

Ecrivez l'ordre des instructions (uniquement les lettres).

Question 4

Voici un programme ; l'utilisateur exécute ce programme et tape SRV-01 à la question posée. 

serveur = input("Quel est le nom du serveur ? ")

Question VRAI FAUX

03

Les conditions

6 points
Question 1

Voici un programme :

if age >= 18:
    print("Accès autorisé")
else:
    print("Accès refusé")

Pour chaque cas, indiquez ce qui s'affiche :

  1. age=15 → affiche : __________________
  2. age=18 → affiche : __________________
  3. age=25 → affiche : __________________
Question 2

Voici un programme :

if moyenne < 10:
    print("Refusé")
elif moyenne < 12:
    print("Passable")
elif moyenne < 14:
    print("Mention Assez Bien")
else:
    print("Mention Bien")

Pour chaque cas, indiquez ce qui s'affiche :

  1. moyenne = 8 → __________________
  2. moyenne = 10 → __________________
  3. moyenne = 13 → __________________
  4. moyenne = 14 → __________________
Question 3

Ecrivez un programme qui doit vérifier l'accès au lycée d'un élève.

  • Le programme demande : le nom d'un élève et du lycée.
  • Si les informations saisient et celles enregistrées sont :
    • Identique, afficher : Accès autorisé.
    • Différente et le nom de l'élève est différent, afficher : Le nom de l'élève n'est pas bon
    • Différente et le nom du lycée est différent, afficher : Le nom du lycée n'est pas bon
    • Sinon, afficher : "Accès impossible."
Question 4

Ecrivez un programme qui doit refuser les mots de passe de moins de 8 caractères.
