Question 2

Voici un programme :

if moyenne < 10:
    print("Refusé")
elif moyenne < 12:
    print("Passable")
elif moyenne < 14:
    print("Mention Assez Bien")
else:
    print("Mention Bien")

Pour chaque cas, indiquez ce qui s'affiche :

  1. moyenne = 8 → __________________
  2. moyenne = 10 → __________________
  3. moyenne = 13 → __________________
  4. moyenne = 14 → __________________
Question 3

Ecrivez un programme qui doit vérifier l'accès au lycée d'un élève.

Pour accéder au lycée, il faut que :

  • Le nom d'un élève et d'un lycée soit enregistés.
  • Le programme demande : le nom d'un élève et du lycée.
  • Si les informations saisient et celles enregistrées sont :
    • Identique, alors afficher : Accès autorisé.
    • Différente et c'est le nom de l'élève qui n'est pas bon, alors afficher : Le nom de l'élève n'est pas bon
    • Différente et c'est le nom du lycée qui n'est pas bon, alors afficher : Le nom du lycée n'est pas bon
    • Sinon, afficher : "Accès impossible."
