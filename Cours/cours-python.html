Introduction à Python

Pourquoi Python ?

Python est un langage de programmation de haut niveau, interprété et polyvalent. Il est particulièrement apprécié pour :

  • Sa simplicité : Syntaxe claire et lisible, proche du langage naturel.
  • Sa polyvalence : On peut l'utiliser dans plein de domaines différents (réseau, administration système, web, cybersécurité, etc..
  • Sa popularité : Un des langage les plus utilisé en entreprise.
  • Son écosystème : Des milliers de bibliothèques disponibles (ex: requests, numpy, pandas, scapy, etc..).

Le Python

Syntaxe et types

Python, langage de Haut niveau

Qu'est-ce que ça veut dire ?

Un programme n'est pas directement envoyé à l'ordinateur, il doit d'abord être transformé par des instruction basique compréhensible par l'ordinateur, par le processseur. Il s'agit du langage machine, composé de séquence en binaire (alternance de 0 et 1).

Ce langage étant quasiement incomphréensible, l'assembleur a été créer. Il permet de coder d'autre langage à partir d'inscruction très simple facilement transposable en langage machine.

Les langages bas-niveau permettent une programmation un peu plus fluide et plus proche du langage naturel. Ils sont peu consomateur d'énergie et économe en mémoire, on les utilise le plus souvent pour de la programmation embarquée (Arduino), avec par exemple le langage C ou C++.

Au sommet de cette pyramide, on trouve les langages haut-niveau. Se sont les langages les plus facile à apprendre car il n'y a pas besoin de gérer les accès à la mémoire. Ils sont souvent utiliser pour concevoir des logiciels complexes ou la manipulation de données. On retrouve dans cette catégorie le langage Python, Java ou JavaScript.

Interagir avec l'utilisateur

Saisie et affichage

Pour communiquer avec l'utilisateur, Python propose deux fonctions très simples :

La fonction input()

La fonction input permet de récupérer une saisie clavier de l'utilisateur :

nom = input("Quel est ton nom ? ")

Les caractères tapés après la question seront alors sauvegardés dans la variable nom.

Dans le terminal, cela donne :

>> Quel est ton nom ? Thomas

La valeur "Thomas" est donc stockée dans la variable nom.

Attention !

input() retourne toujours du texte (un str), même si l'utilisateur tape un nombre.
Exemple : Si l'utilisateur tape 25, la variable contiendra la chaîne "25", pas le nombre 25.

La fonction print()

La fonction print permet d'afficher du texte ou le contenu d'une variable à l'écran :

print("Bonjour")  # Affiche : Bonjour

Pour afficher le contenu d'une variable, on utilise + pour concaténer :

prenom = "Thomas"
print("Bonjour " + prenom + " !")  # Affiche : Bonjour Thomas !

Exemple complet

Voici un programme qui demande le prénom de l'utilisateur et l'affiche :

prenom = input("Quel est ton prénom ? ")
print("Bonjour " + prenom + " !")

Dans le terminal, cela donne :

>> Quel est ton prénom ? Thomas
Bonjour Thomas !

Prendre des décisions avec if

Conditions

Les conditions permettent d'exécuter du code différent en fonction d'une situation. En Python, on utilise if, elif et else pour cela.

La structure if

Voici comment fonctionne une condition :

if [condition]:
    # Code exécuté si la condition est vraie
else:
    # Code exécuté si la condition est fausse

Exemple : Vérifier si un nombre est positif

Voici un programme qui vérifie si un nombre est positif ou négatif :

nombre = int(input("Saisis un nombre : "))
if nombre > 0:
    print("Le nombre est positif.")
else:
    print("Le nombre est négatif ou nul.")

Dans le terminal, cela donne :

>> Saisis un nombre : 5
        Le nombre est positif.

Ajouter d'autres cas avec elif

Si vous avez plusieurs cas à vérifier, utilisez elif (qui veut dire "sinon si") : 

nombre = int(input("Saisis un nombre : "))
if nombre > 0:
    print("Le nombre est positif.")
elif nombre < 0:
    print("Le nombre est négatif.")
else:
    print("Le nombre est nul.")
Opérateurs de comparaison

Voici les opérateurs que vous pouvez utiliser dans une condition :

Opérateur Signification Exemple
== Égal à if age == 18:
!= Différent de if age != 18:
< Inférieur à if age < 18:
> Supérieur à if age > 18:
<= Inférieur ou égal à if age <= 18:
>= Supérieur ou égal à if age >= 18:

Répéter des actions avec les boucles

Boucles

Les boucles permettent de répéter une action plusieurs fois sans avoir à réécrire le même code. En Python, il y a deux types de boucles : for et while.

La boucle for

La boucle for permet de parcourir une liste ou une séquence de valeurs. 

# Parcourir une liste de fruits
fruits = ["pomme", "banane", "orange"]
for fruit in fruits:
    print(fruit)

Dans le terminal, cela donne :

pomme
banane
orange

On peut aussi utiliser for avec range() pour répéter une action un certain nombre de fois :

# Afficher les nombres de 0 à 4
for i in range(5):
    print(i)

Dans le terminal, cela donne :

0
1
2
3
4

La boucle while

La boucle while permet de répéter une action tant qu'une condition est vraie. 

# Compter de 1 à 5
i = 1
while i <= 5:
    print(i)
    i = i + 1

Dans le terminal, cela donne :

1
2
3
4
5
Attention aux boucles infinies !

Si la condition de la boucle while est toujours vraie, la boucle ne s'arrêtera jamais.
Exemple : 

while True:
print("C'est infini !")
→ Ce programme ne s'arrêtera jamais !

Exemple concret : Demander un nombre positif

Voici un programme qui demande à l'utilisateur de saisir un nombre positif :

nombre = -1
while nombre < 0:
    nombre = int(input("Saisis un nombre positif : "))
print("Tu as saisi : " + str(nombre))

Dans le terminal, cela donne :

>> Saisis un nombre positif : -5
>> Saisis un nombre positif : 10
Tu as saisi : 10

Les listes

Stocker plusieurs valeurs

Une liste permet de stocker plusieurs valeurs dans une seule variable. C'est très utile pour regrouper des données, comme une liste de noms, de nombres, ou d'adresses IP.

Créer une liste

Pour créer une liste, on utilise des crochets [] et on sépare les valeurs par des virgules :

# Liste de noms
noms = ["Alice", "Bob", "Charlie"]

# Liste de nombres
nombres = [1, 2, 3, 4, 5]

# Liste vide
vide = []

Accéder à un élément de la liste

Chaque élément d'une liste a un index (un numéro qui indique sa position). Le premier élément a l'index 0, le deuxième l'index 1, etc. 

fruits = ["pomme", "banane", "orange"]

# Accéder au premier élément (index 0)
print(fruits[0])  # Affiche : pomme

# Accéder au deuxième élément (index 1)
print(fruits[1])  # Affiche : banane

# Accéder au dernier élément (index -1)
print(fruits[-1])  # Affiche : orange
Attention !

Si vous essayez d'accéder à un index qui n'existe pas, Python affichera une erreur : 

fruits = ["pomme", "banane"]
print(fruits[5])  # ❌ Erreur : IndexError

Modifier une liste

On peut ajouter, supprimer ou remplacer des éléments dans une liste.

# Ajouter un élément à la fin
fruits = ["pomme", "banane"]
fruits.append("orange")  # Ajoute "orange" à la fin
print(fruits)  # Affiche : ["pomme", "banane", "orange"]

# Supprimer un élément
fruits.remove("banane")  # Supprime "banane"
print(fruits)  # Affiche : ["pomme", "orange"]

# Remplacer un élément
fruits[0] = "poire"  # Remplace "pomme" par "poire"
print(fruits)  # Affiche : ["poire", "orange"]

Connaître la taille d'une liste

Pour savoir combien il y a d'éléments dans une liste, on utilise la fonction len() :

fruits = ["pomme", "banane", "orange"]
print(len(fruits))  # Affiche : 3

Les fonctions en Python

Modularité et réutilisabilité

Les fonctions permettent de structurer votre code en blocs réutilisables. Elles sont essentielles pour écrire du code propre, maintenable et efficace.

🎯 Pourquoi utiliser des fonctions ?

Les fonctions offrent plusieurs avantages :

  • Réutilisabilité : Éviter de copier-coller du code.
  • Lisibilité : Code plus structuré et facile à comprendre.
  • Maintenance : Corriger un bug dans une fonction corrige le bug partout où elle est appelée.
  • Abstraction : Masquer les détails d'implémentation.
graph TD A[Code sans fonctions] -->|Chaotique| B[Difficile à maintenir] C[Code avec fonctions] -->|Organisé| D[Facile à maintenir]

📝 Syntaxe d'une fonction

Voici la syntaxe de base pour déclarer une fonction en Python : 

def nom_fonction(param1, param2):
    """Docstring : description de la fonction."""
    # Code de la fonction
    return valeur_de_retour  # Optionnel
Exemple simple : Dire bonjour 
def dire_bonjour(nom):
    """Affiche un message de salutation."""
    print(f"Bonjour", nom, "!")

# Appel de la fonction
dire_bonjour("Alice")  # Affiche : Bonjour, Alice!
Exemple avec valeur de retour 
def calculer_carre(nombre):
    """Retourne le carré d'un nombre."""
    return nombre ** 2

# Appel de la fonction
resultat = calculer_carre(5)  # resultat = 25
print(f"Le carré de 5 est {resultat}.")

📥 Paramètres et valeurs de retour

Paramètres obligatoires

Les paramètres obligatoires doivent être fournis lors de l'appel de la fonction : 

def dire_bonjour(nom):  # nom est obligatoire
    print(f"Bonjour, {nom}!")

dire_bonjour("Alice")  # ✅ OK
dire_bonjour()        # ❌ Erreur : il manque un argument
Paramètres par défaut

Vous pouvez définir des valeurs par défaut pour les paramètres : 

def dire_bonjour(nom="inconnu"):  # nom a une valeur par défaut
    print(f"Bonjour, {nom}!")

dire_bonjour("Alice")   # Affiche : Bonjour, Alice!
dire_bonjour()          # Affiche : Bonjour, inconnu!
Paramètres nommés

Vous pouvez passer les paramètres par nom pour plus de clarté : 

def creer_utilisateur(nom, age, ville="Paris"):
    print(f"{nom}, {age} ans, {ville}")

creer_utilisateur("Alice", 25)          # ville = "Paris" (par défaut)
creer_utilisateur("Bob", 30, ville="Lyon")  # Paramètre nommé
Valeurs de retour multiples

Une fonction peut retourner plusieurs valeurs sous forme de tuple : 

def get_min_max(nombres):
    return min(nombres), max(nombres)  # Retourne un tuple

min_val, max_val = get_min_max([5, 2, 8, 1, 9])
print(f"Min : {min_val}, Max : {max_val}")  # Affiche : Min : 1, Max : 9

📖 Docstrings : Documenter ses fonctions

Les docstrings sont des chaînes de caractères placées en début de fonction pour la documenter. Elles sont essentielles pour :

  • Expliquer à quoi sert la fonction.
  • Décrire les paramètres et leur type.
  • Indiquer la valeur de retour et son type.
Format d'une docstring 
def ma_fonction(param1, param2):
    """Description courte de la fonction.

    Args:
        param1 (type): Description du paramètre 1.
        param2 (type): Description du paramètre 2.

    Returns:
        type: Description de la valeur de retour.
    """
    # Code de la fonction
    return valeur
Exemple complet avec docstring 
def calculer_moyenne(notes):
    """Calcule la moyenne d'une liste de notes.

    Args:
        notes (list): Liste de nombres (float ou int).

    Returns:
        float: La moyenne des notes.

    Raises:
        ValueError: Si la liste est vide.
    """
    if len(notes) == 0:
        raise ValueError("La liste de notes ne peut pas être vide.")
    return sum(notes) / len(notes)

Gestion des erreurs en Python

try/except/raise

La gestion des erreurs permet de rendre votre code plus robuste et plus user-friendly. En Python, on utilise try, except, else, et finally pour gérer les exceptions.

❓ Pourquoi gérer les erreurs ?

Gérer les erreurs permet de :

  • Éviter que le programme plante à cause d'une entrée invalide.
  • Informer l'utilisateur de manière claire (ex: "Veuillez saisir un nombre").
  • Logger les erreurs pour le débogage (ex: écrire dans un fichier de logs).
  • Nettoyer les ressources (ex: fermer un fichier même en cas d'erreur).
Exemple : Sans gestion d'erreur 
# Ce programme plante si l'utilisateur saisi un texte
nombre = int(input("Saisir un nombre : "))
print(f"Vous avez saisi : {nombre}")

Problème : Si l'utilisateur saisi "abc", le programme affiche une erreur ValueError et s'arrête.

Exemple : Avec gestion d'erreur 
try:
    nombre = int(input("Saisir un nombre : "))
    print(f"Vous avez saisi : {nombre}")
except ValueError:
    print("Erreur : veuillez saisir un nombre valide.")

Avantage : Le programme ne plante pas et informe l'utilisateur de l'erreur.

🛡️ Syntaxe de base : try/except

La syntaxe de base pour attraper une erreur : 

try:
    # Code qui peut lever une erreur
    resultat = 10 / 0
except ZeroDivisionError:
    # Code exécuté si une erreur se produit
    print("Erreur : division par zéro.")
Attraper plusieurs types d'erreurs 
try:
    nombre = int(input("Saisir un nombre : "))
    resultat = 10 / nombre
    print(f"Résultat : {resultat}")
except ValueError:
    print("Erreur : veuillez saisir un nombre valide.")
except ZeroDivisionError:
    print("Erreur : division par zéro.")
Attraper toutes les erreurs (à utiliser avec précaution) 
try:
    # Code risqué
    resultat = 10 / int(input("Saisir un nombre : "))
except Exception as e:
    # Attrape TOUTES les erreurs
    print(f"Une erreur est survenue : {e}")

⚠️ Attention : Attraper toutes les erreurs peut masquer des bugs inattendus. Préférez attraper des erreurs spécifiques.

📌 Types d'erreurs courants

Voici les exceptions les plus courantes en Python :

Exception Cause Exemple
ValueError Valeur invalide (ex: conversion impossible). int("abc")
TypeError Opération impossible entre types. "5" + 3
IndexError Index hors des limites (ex: liste[10] si len(liste) == 5). ma_liste[10]
KeyError Clé manquante dans un dictionnaire. mon_dico["clef_inexistante"]
FileNotFoundError Fichier introuvable. open("fichier_inexistant.txt")
ZeroDivisionError Division par zéro. 10 / 0
NameError Variable non définie. print(x) (si x n'est pas défini)
AttributeError Attribut ou méthode inexistant. "abc".append("d") (les chaînes n'ont pas de méthode append)

🔄 else et finally

else et finally sont des blocs optionnels qui peuvent être utilisés avec try/except :

else : Code exécuté si aucune erreur ne se produit 
try:
    resultat = 10 / 2
except ZeroDivisionError:
    print("Division par zéro.")
else:
    print(f"Résultat : {resultat}")  # Exécuté si aucune erreur
finally : Code exécuté dans tous les cas 
try:
    fichier = open("data.txt", "r")
    contenu = fichier.read()
except FileNotFoundError:
    print("Fichier introuvable.")
finally:
    fichier.close()  # Fermer le fichier dans tous les cas

Utilité : finally est utile pour nettoyer des ressources (ex: fermer un fichier, une connexion réseau).

🚨 Lever ses propres erreurs avec raise

Vous pouvez lever vos propres exceptions avec le mot-clé raise :

Exemple : Lever une ValueError 
def diviser(a, b):
    if b == 0:
        raise ValueError("Le dénominateur ne peut pas être zéro.")
    return a / b

# Utilisation
try:
    resultat = diviser(10, 0)
except ValueError as e:
    print(f"Erreur : {e}")  # Affiche : Erreur : Le dénominateur ne peut pas être zéro.
Créer des exceptions personnalisées 
# Définir une nouvelle exception
class ErreurPersonnalisee(Exception):
    pass

# Lever l'exception
def ma_fonction(valeur):
    if valeur < 0:
        raise ErreurPersonnalisee("La valeur ne peut pas être négative.")
    return valeur * 2

# Utilisation
try:
    resultat = ma_fonction(-5)
except ErreurPersonnalisee as e:
    print(f"Erreur : {e}")  # Affiche : Erreur : La valeur ne peut pas être négative.
