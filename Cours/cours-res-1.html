01

Le réseau en une image

Vue d'ensemble

Un réseau = des équipements (nœuds) + des liens (câbles, Wi-Fi) + des règles communes (les protocoles). Voici l'organisation type d'un réseau d'entreprise ou de lycée :

                                  INTERNET
                                     │
                              ┌──────┴──────┐
                              │  PARE-FEU   │  filtre ce qui entre et sort
                              │  + PROXY    │  (souvent dans le routeur)
                              └──────┬──────┘
                                  ┌──┴───┐
                                  │ROUTEUR│  ← la PASSERELLE (adresse publique côté internet)
                                  └──┬───┘
                              ┌──────┴──────┐
                              │    SWITCH   │  baie de brassage / local technique
                              └─┬────┬────┬─┘
                                │    │    │
                          ┌─────┴┐ ┌─┴────┐ ┌┴─────────┐
                          │ PC 1 │ │ PC 2 │ │ SERVEUR  │  DNS · DHCP · web · fichiers
                          └──────┘ └──────┘ └──────────┘
                                +
                          bornes Wi-Fi (dans les salles, reliées au switch)
Je retiens

Switch = relie un réseau local. Routeur = relie des réseaux différents (passerelle). Pare-feu/proxy = filtre vers internet. Serveurs = rendent des services.

02

Les équipements

Qui fait quoi

🔌 Les équipements physiques

Équipement Couche Rôle Où le trouver
Switch 2 (MAC) Relie les machines d'un même réseau local ; envoie chaque trame sur le bon port Baie de brassage, salle
Routeur 3 (IP) Relie des réseaux différents ; choisit la route ; sert de passerelle Sortie du réseau
Point d'accès Wi-Fi 2 Relie les appareils sans fil au réseau filaire Plafonds des salles
Serveur — Rend des services : web, DNS, DHCP, fichiers… Salle des serveurs

🧰 Les équipements logiciels

Équipement Rôle Où le voir
Pare-feu Filtre le trafic vers/depuis internet selon des règles À la sortie du réseau
Proxy Relais web : contrôle et met en cache Avec le pare-feu
Passerelle « Porte de sortie » du réseau local (c'est un rôle, souvent le routeur) Champ passerelle de ipconfig /all
DNS Traduit un nom en adresse IP nslookup
DHCP Distribue les adresses IP (bails) ipconfig /all
Windows / Linux Server Systèmes qui hébergent tous ces services Salle des serveurs

🧭 Switch ou routeur ? Le schéma qui évite les erreurs

   RÉSEAU A (192.168.10.0)                RÉSEAU B (192.168.20.0)
   PC1 .11 ─┐                             PC5 .11 ─┐
   PC2 .12 ─┤─[ SW-A ]───┐   ┌─────────┐ ┌─[ SW-B ]─┤ PC6 .12
   SRV .10 ─┘            ├───┤ ROUTEUR ├──┘          ┘
                          │   └─────────┘
                          │    if A : 192.168.10.254  (dans le réseau A)
                          │    if B : 192.168.20.254  (dans le réseau B)
                          ┘
   Le switch ne connaît que les MAC de SON réseau.
   Dès que la destination est dans un AUTRE réseau →
   le poste envoie le paquet à sa PASSERELLE (l'interface du routeur dans son réseau).
03

Le modèle OSI : 7 couches

Modèles

La communication est complexe : on la découpe en 7 couches, chacune avec un rôle précis. Le modèle TCP/IP (4 couches), plus proche de la réalité, leur correspond presque un pour un.

N° Couche Rôle Exemples Équipement
7 Application Interface avec les logiciels HTTP, DNS, DHCP Serveurs, postes
6 Présentation Format, chiffrement TLS/SSL —
5 Session Ouvre et gère les dialogues NetBIOS, RPC —
4 Transport Fiabilité, ports TCP, UDP —
3 Réseau Adresses IP, routage IP, ICMP, ARP Routeur
2 Liaison Adresses MAC, trames Ethernet, Wi-Fi Switch
1 Physique Signaux, câbles RJ45, fibre, ondes Câblage

Moyen mnémotechnique (1 → 7) : Physique, Liaison, Réseau, Transport, Session, Présentation, Application.

🧅 L'encapsulation : l'empilement en schéma

   POSTE ÉMETTEUR (descendant)           POSTE DESTINATAIRE (remontant)
   ┌─────────────────────────┐           ┌─────────────────────────┐
   │ 7-5 : les données       │           │ 7-5 : les données       │ ◄ le navigateur lit la page
   ├─────────────────────────┤           ├─────────────────────────┤
   │ 4 : + ports TCP/UDP     │           │ 4 : − ports             │
   ├─────────────────────────┤           ├─────────────────────────┤
   │ 3 : + IP source/dest    │  ───►     │ 3 : − IP                │ ◄ le routeur lit les IP
   ├─────────────────────────┤  le paquet├─────────────────────────┤
   │ 2 : + MAC source/dest   │  voyage   │ 2 : − MAC               │ ◄ le switch lit les MAC
   ├─────────────────────────┤           ├─────────────────────────┤
   │ 1 : signaux sur le câble│           │ 1 : signaux             │
   └─────────────────────────┘           └─────────────────────────┘

   En descendant : chaque couche EMBALLE (ajoute ses informations).
   En remontant : chaque couche DÉBALLE (retire son information et la lit).
Je retiens

Couche 2 = MAC (switch) · couche 3 = IP (routeur) · couche 4 = TCP/UDP · couches 5-7 = applications. Le switch et le routeur ne lisent pas les mêmes adresses : c'est pour ça qu'ils ne travaillent pas à la même couche.

04

Les adresses en bref

Repères
Adresse À quoi elle sert Exemple / repère
IP (couche 3) Adresse logique : où est la machine sur le réseau 192.168.10.11 — donnée par le DHCP
MAC (couche 2) Adresse physique : identité de la carte réseau A4-5E-60-... — gravée
Privée Réseau local, non routable sur internet 10.x, 172.16-31.x, 192.168.x
Publique Routable sur internet, donnée par l'opérateur 82.64.12.37 — le NAT traduit
Réseau / diffusion .0 = le réseau, .255 = tous les postes (en /24) Jamais attribuées à une machine
APIPA Auto-attribuée quand le DHCP ne répond pas 169.254.x.x = panne DHCP
05

Les commandes du technicien

Mémo
Commande Ce qu'elle fait
ipconfig /all Toute la configuration du poste : IP, masque, passerelle, DNS, MAC, bail DHCP
ping <adresse> Teste si une machine répond (protocole ICMP)
tracert <adresse> Liste les équipements traversés jusqu'à la destination
nslookup <nom> Interroge le DNS : nom → adresse IP
arp -a Affiche la table IP ↔ MAC des voisins connus
Démarche de diagnostic (dans l'ordre)

ping 127.0.0.1 (ma pile) → ping ma passerelle (mon réseau local) → ping 8.8.8.8 (internet) → nslookup www.google.com (le DNS). Où ça casse, là est la panne.
