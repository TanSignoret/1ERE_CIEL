03

TP 2 — Révision des bases de Python

5 exercices

Dans ce TP, tu vas écrire 5 scripts Python pour automatiser des tâches simples chez RéseauPro. Chaque script doit être testé et fonctionnel avant de passer à l'exercice suivant.

  1. 1
    Gestion des variables et entrée/sortie

    Contexte : Ton tuteur te demande de créer un script pour enregistrer les informations d'un nouveau serveur.

    Consignes :

    • Demander à l'utilisateur de saisir :
      • Le nom du serveur (ex: "SRV-WEB-01").
      • L'adresse IP du serveur (ex: "192.168.1.1").
      • Le nombre de ports ouverts (ex: 3).
    • Afficher un message de confirmation avec les informations saisies : 
      Le serveur [nom] a pour adresse IP [IP] et a [ports] ports ouverts.
    Exemple

    Si l'utilisateur saisi SRV-WEB-01, 192.168.1.1 et 3, le script doit afficher :

    Le serveur SRV-WEB-01 a pour adresse IP 192.168.1.1 et a 3 ports ouverts.
  2. 2
    Vérification de configuration avec conditions

    Contexte : RéseauPro impose des règles pour les mots de passe des serveurs : ils doivent faire au moins 8 caractères.

    Consignes :

    • Demander à l'utilisateur de se créer un compte (saisir un nom et mot de passe). Stocker ces informations dans 2 variables.
    • Demander à l'utilisateur de saisir un nom et un mot de passe.
    • Pour se connecter, il faut que :
      • Le mot de passe et le nom correspond aux informations préalablement enregistrée. Si c'est bien le cas, afficher : "Connexion effectué"
      • Si c'est le mot de passe qui n'est pas bon, afficher : "Mot de passe incorect"
      • Si c'est le nom qui n'est pas bon, afficher : "Nom incorect"
      • Sinon, afficher : "Connexion impossible."
  3. 3
    Simuler un scan de ports avec une boucle for

    Contexte : Ton tuteur te demande de simuler un scan des ports 22, 80 et 443 sur un serveur.

    Consignes :

    • Utiliser une boucle for pour parcourir les ports 22, 80 et 443.
    • Pour chaque port, afficher : 
      Scanne le port [port]...
    Exemple

    Le script doit afficher :

    Scanne le port 22...
Scanne le port 80...
Scanne le port 443...
    Astuce

    Utilisez une liste pour stocker les ports : ports = [22, 80, 443], puis parcours-la avec for port in ports:.

  4. 4
    Vérification de connexion avec une boucle while

    Contexte : Ton tuteur te demande de créer un script qui demande à l'utilisateur de saisir un code de connexion valide.

    Consignes :

    • Le code de connexion valide est "CIEL2026".
    • Utiliser une boucle while pour demander à l'utilisateur de saisir un code jusqu'à ce qu'il soit valide.
    • Si le code est incorrect, afficher : "Code incorrect. Réessayez."
    • Si le code est correct, afficher : "Accès autorisé." et quitter la boucle.
    Exemple

    Si l'utilisateur saisi "ABC123", puis "CIEL2026", le script doit afficher :

    Code incorrect. Réessayez.
Accès autorisé.
  5. 5
    Gestion d'une liste d'adresses IP

    Contexte : Ton tuteur te demande de gérer une liste d'adresses IP pour un réseau local.

    Consignes :

    • Créer une liste avec les adresses IP suivantes : ["192.168.1.1", "192.168.1.2", "192.168.1.3"].
    • Afficher la deuxième adresse IP de la liste.
    • Ajouter une quatrième adresse IP ("192.168.1.4") à la liste.
    • Afficher toute la liste mise à jour.
    Exemple

    Le script doit afficher :

    Deuxième adresse IP : 192.168.1.2
Liste complète : ['192.168.1.1', '192.168.1.2', '192.168.1.3', '192.168.1.4']
    Astuce

    Pour accéder à un élément d'une liste, utilisez son index entre crochets : ma_liste[1] (l'index commence à 0).

    Pour ajouter un élément à une liste, utilisez ma_liste.append("valeur").

04

Lexique

Vocabulaire
Mot Définition
Variable Espace de stockage pour une valeur (ex: nom = "SRV-01").
int Type de variable pour les nombres entiers (ex: age = 25).
float Type de variable pour les nombres à virgule (ex: pi = 3.14).
str Type de variable pour les chaînes de caractères (ex: nom = "CIEL").
input() Fonction pour demander une entrée à l'utilisateur.
print() Fonction pour afficher un texte ou une variable.
Condition (if) Structure qui exécute du code en fonction d'une condition (ex: if x > 0:).
Boucle for Structure qui répète une action pour chaque élément d'une séquence (ex: for i in range(5):).
Boucle while Structure qui répète une action tant qu'une condition est vraie (ex: while x < 10:).
Liste Collection ordonnée de valeurs (ex: ips = ["192.168.1.1", "192.168.1.2"]).
