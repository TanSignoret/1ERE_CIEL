02

Introduction

Prérequis

Chez ProgPro, l'équipe utilise Git pour :

  • Sauvegarder l'historique des modifications des scripts.
  • Collaborer à plusieurs sur les mêmes fichiers sans écraser le travail des autres.
  • Revenir en arrière si une modification casse le code.

Vous allez d'abord utiliser LearnGitBranching, un outil visuel pour comprendre Git, puis créer votre propre dépôt sur GitHub.

Matériel nécessaire

Pour suivre ce TP, vous aurez besoin de :

  • Un poste informatique avec accès à Internet.
  • Un navigateur web (Firefox, Chrome, Edge).
  • Un compte GitHub (à créer si ce n'est pas déjà fait).
  • Les scripts du TP 1 (à récupérer depuis OnlineIDE).
03

TP 2 — Découverte de Git avec LearnGitBranching

4 étapes

Dans ce TP, vous allez :

  1. Découvrir Git avec LearnGitBranching.
  2. Créer un dépôt GitHub et y ajouter vos scripts du TP 1.
  3. Configurer VS Code pour utiliser Git.
  1. 1
    Découvrir Git avec LearnGitBranching

    Rends-toi sur LearnGitBranching et suis les instructions pour compléter les niveaux suivants :

    • Introduction Sequence : Niveaux 1 à 3.
      • Apprendre à créer des commits.
      • Comprendre l'historique des modifications.
    • Branching in Git : Niveaux 1 à 4.
      • Créer et changer de branche.
      • Fusionner des branches (git merge).
      • Comprendre les conflits.
    Conseil

    Si vous bloquez sur un niveau, utilise le bouton "Show Solution" pour voir la réponse, puis recommence.

    Validation

    Tu as validé tous les niveaux demandés sur LearnGitBranching.

  2. 2
    Créer un dépôt GitHub

    Contexte : Votre tuteur te demande de sauvegarder tes scripts du TP 1 dans un dépôt GitHub pour pouvoir les partager avec l'équipe.

    Consignes :

    1. Crée un compte GitHub si ce n'est pas déjà fait (github.com).
    2. Crée un nouveau dépôt :
      • Nom : BacPro_CIEL_Dev.
      • Description : Dépôt pour les TP de développement Python et Git.
      • Visibilité : Public (pour que votre professeur puisse voir votre travail).
      • Ne pas cocher "Add a README" ou "Add .gitignore".
    3. Une fois le dépôt créé, copier le code des 4 scripts du TP 1 dans des fichiers séparés (ex: tp1_exercice1.py, tp1_exercice2.py, etc.).
    4. Ajoute ces fichiers à votre dépôt :
      • Glisse-dépose les fichiers dans la page GitHub.
      • Ou clique sur "Add file" → "Upload files".
    5. Fais un commit pour chaque script avec un message clair (ex: Ajout exercice 1 : calcul de moyenne).
    Exemple de commit

    Message de commit :

    Ajout exercice 2 : vérification mot de passe
    Validation

    Ton dépôt GitHub contient les 4 scripts du TP 1, avec un commit par script.

  3. 3
    Cloner le dépôt en local

    Contexte : Pour travailler efficacement, vous devez dois avoir une copie locale de votre dépôt.

    Consignes :

    1. Sur la page de votre dépôt GitHub, clique sur "Code" (bouton vert).
    2. Copie l'URL HTTPS du dépôt (ex: https://github.com/utilisateur/BacPro_CIEL_Dev.git).
    3. Ouvre le terminal (ou l'invite de commandes) et exécute : 
      git clone https://github.com/utilisateur/BacPro_CIEL_Dev.git
    4. Un dossier BacPro_CIEL_Dev est créé sur votre poste. Ouvre-le pour vérifier que tes scripts sont bien présents.
    Astuce

    Si vous n'avez pas Git installé, télécharge-le ici.

    Validation

    Tu as un dossier BacPro_CIEL_Dev sur votre poste avec les 4 scripts du TP 1.

  4. 4
    Installer VS Code et ses extensions

    Contexte : VS Code est l'IDE utilisé par l'équipe de RéseauPro. Vous devez l'installer et le configurer pour les prochains TP.

    Consignes :

    1. Télécharger et installer VS Code.
    2. Ouvrir VS Code et installer les extensions suivantes :
      • Python (par Microsoft) : pour coder en Python.
      • GitLens : pour visualiser les changements Git.
      • Code Runner : pour exécuter rapidement du code.
    3. Ouvrir le dossier BacPro_CIEL_Dev dans VS Code (via Fichier → Ouvrir le dossier).
    4. Vérifier que vous voyez bien tes 4 scripts du TP 1 dans l'explorateur de fichiers.
    Astuce

    Pour installer une extension :

    1. Ouvre le panneau des extensions (Ctrl + Shift + X).
    2. Recherche le nom de l'extension (ex: Python).
    3. Clique sur Installer.
    Validation

    VS Code est installé avec les 3 extensions, et votre dépôt BacPro_CIEL_Dev est ouvert.

04

Lexique

Vocabulaire
Mot Définition
Git Système de gestion de versions : permet de sauvegarder l'historique des modifications d'un projet.
Dépôt (Repository) Dossier où Git stocke l'historique des modifications d'un projet.
Commit Sauvegarde d'un état du code à un instant donné, avec un message descriptif.
Branche (Branch) Version parallèle du code, utilisée pour développer une nouvelle fonctionnalité sans affecter la version principale.
Merge Fusionner les modifications d'une branche dans une autre (ex: fusionner une branche feature dans main).
GitHub Plateforme en ligne pour héberger des dépôts Git et collaborer avec d'autres développeurs.
Clone Récupérer une copie locale d'un dépôt distant (ex: depuis GitHub).
IDE Environnement de Développement Intégré (ex: VS Code) : outil pour écrire, tester et déboguer du code.
