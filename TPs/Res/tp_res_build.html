Pourquoi un simulateur ?

Filius est un simulateur de réseau pédagogique : on y construit le réseau complet avant de le câbler pour de vrai. Tout ce que vous ferez aujourd'hui (câblage, adressage, tests) se refait à l'identique sur du matériel réel.

03

Chantier 1 — Reconstruire le réseau de l'atelier (guidé)

1 h
Situation professionnelle

Vous êtes en stage chez Tech'Usine, une petite entreprise de maintenance. Le réseau de l'atelier existe déjà mais le technicien n'a pas de maquette pour le présenter. Il vous confie une mission simple : « Reconstruis notre réseau dans Filius, en suivant exactement le dossier technique ci-dessous, puis vérifie que tout communique. » Aucune décision à prendre : appliquez les valeurs données, et concentrez-vous sur la manipulation du logiciel.

Le dossier technique de l'atelier

Le réseau de l'atelier est un réseau 192.168.10.0, masque 255.255.255.0. Il comporte un switch, deux postes de travail et un serveur :

                    ┌──────────────────┐
                    │    SW-ATELIER    │   switch
                    └──┬─────┬─────┬───┘
                       │     │     │
             ┌─────────┘     │     └─────────┐
             │               │               │
      ┌──────┴──────┐ ┌──────┴──────┐ ┌──────┴──────┐
      │     SRV     │ │ PC-ATELIER-1│ │ PC-ATELIER-2│
      │192.168.10.10│ │192.168.10.11│ │192.168.10.12│
      │ IP fixe     │ │ IP fixe     │ │ DHCP        │
      │DHCP+DNS+Web │ │             │ │ 192.168.10.x│
      └─────────────┘ └─────────────┘ └─────────────┘
        Réseau : 192.168.10.0 · Masque : 255.255.255.0 · DNS : intranet.techusine.fr → 192.168.10.10
Élément Adresse IP Masque Remarque
Réseau de l'atelier 192.168.10.0 255.255.255.0 plage privée
SRV (serveur) 192.168.10.10 255.255.255.0 IP fixe — sert DHCP, DNS et web
PC-ATELIER-1 192.168.10.11 255.255.255.0 IP fixe
PC-ATELIER-2 donnée par DHCP 255.255.255.0 à partir de 192.168.10.100
Nom interne du serveur intranet.techusine.fr — enregistrement DNS

À vous de jouer

  1. 1
    Découvrir les trois modes de Filius
    • En haut à droite, repérez les 3 modes : 🔨 Design (le marteau — on construit la maquette), ▶️ Simulation (la flèche verte — le réseau « vit »), ✏️ Documentation (le crayon — on annote).
    • Restez en mode Design pour construire ; on passera en Simulation pour les tests.
  2. 2
    Placer et nommer les machines
    • Dans la barre de gauche, glissez 2 Notebook (les clients) et 1 PC (le serveur) dans la zone de travail.
    • Renommez-les : PC-ATELIER-1, PC-ATELIER-2, SRV — clic droit → Rename (ou champ Name dans la configuration).
    Réflexe de technicien

    On renomme toujours les équipements dès qu'on les pose : un schéma plein de « Notebook 1, PC 2 » ne se lit pas et provoque des erreurs.

  3. 3
    Câbler en étoile
    • Glissez un Switch au centre et renommez-le SW-ATELIER.
    • Cliquez sur l'outil câble (dans la barre de gauche), puis cliquez sur un équipement et sur le switch pour poser le lien. Répétez pour les 3 machines, comme sur le schéma du dossier.
    • Passez en mode Simulation (flèche verte)
    • Réduire le slider de rapidité, en faut de la fenpetre à 30%.
    • Faire doule click sur un des équipements puis Installation de logiciel, déplacer invite de commande à gauche.
    • Faire un ping vers un autre équipement du réseau et vérifier que les liaisons fonctionnent bien.
    Validation

    Les 3 câbles sont posés et les voyants sont verts en mode Simulation.

  4. 4
    Saisir les adresses IP fixes du dossier
    • Retournez en mode Design. Sur SRV : double-clic (ou clic droit → Configure) → onglet réseau → IP 192.168.10.10, masque 255.255.255.0.
    • Sur PC-ATELIER-1 : même chose avec 192.168.10.11.
    • PC-ATELIER-2 reste pour l'instant sans configuration automatique : on l'adressera par DHCP à l'étape 6.
  5. 5
    Installer la ligne de commande et prouver que les postes communiquent
    • Sur PC-ATELIER-1 : double-clic → dans la liste d'applications, installez Command Line (glissez-la sur le bureau du poste), puis passez en mode Simulation, double-cliquez sur le poste et lancez Command Line.

    Toujours dans Command Line de PC-ATELIER-1, testez dans l'ordre et notez chaque résultat :

    N° Commande à taper Réponse attendue Mon résultat ✔ / ✘
    1 ping 127.0.0.1 réponses de 127.0.0.1
    2 ping 192.168.10.11 réponses de sa propre IP
    3 ping 192.168.10.10 réponses de SRV
    Question 1

    Comment appelle-t-on un message envoyé à toutes les machines du réseau en même temps ?

  6. 6
    Mettre le serveur DHCP en service

    Le dossier précise que PC-ATELIER-2 reçoit son adresse automatiquement. C'est le rôle du serveur DHCP installé sur SRV :

    • Sur SRV (mode Design) : installez l'application DHCP Server, puis double-cliquez dessus.
    • Renseignez les réglages du dossier : Début de plage = 192.168.10.100, Fin de plage = 192.168.10.200, masque 255.255.255.0, passerelle 0.0.0.0 (pas encore de routeur), DNS 192.168.10.10. Cochez Activer le service DHCP.
    • Sur PC-ATELIER-2 : dans la configuration réseau, cochez Adressage automatique (DHCP).
    • Passez en mode Simulation, ouvrez Command Line sur PC-ATELIER-2 et tapez ipconfig : notez l'adresse reçue.
    Question 2

    L'adresse reçue par PC-ATELIER-2 est-elle dans la plage définie sur le serveur ? Qui a choisi cette adresse : le PC ou le serveur ?

  7. 7
    Mettre le serveur DNS et le site web en service
    • Sur SRV : installez DNS Server, lancez-le, ajoutez l'enregistrement du dossier : nom intranet.techusine.fr → adresse 192.168.10.10, bouton Add, puis Start.
    • Toujours sur SRV : installez Web Server, lancez-le (double-clic sur le bureau du serveur) et appuyez sur Start : SRV héberge maintenant le site interne de l'entreprise.
    • Sur PC-ATELIER-1 : installez un Webbrowser, ouvrez-le et tapez l'URL http://192.168.10.10 : la page du serveur s'affiche.
    • Maintenant tapez http://intranet.techusine.fr : même page, mais par le nom.
    Question 3

    Quelle information le DNS a-t-il fournie au navigateur pour qu'il trouve la page ?

    Chantier 1 terminé

    Sauvegardez : chantier1_atelier.fls.

Chantier 2 — Construire le réseau du local technique (autonome)

45 min
Situation professionnelle n°2

Le lendemain, votre tuteur a validé votre intervention sur le poste n°1 et vous confie maintenant la mise en service du réseau complet du local technique : 3 postes de travail et 1 serveur (DHCP + DNS + web).

Cette fois, le dossier technique n'existe pas encore : c'est a vous de le faire le technicien.

Méthode : vous refaites exactement les mêmes gestes qu'au chantier 1 mais avec vos propres valeurs.

  1. 1
    Choisir le plan d'adressage

    Le local technique compte 4 machines — et l'entreprise prévoit d'en ajouter d'autres plus tard. Choisissez un réseau privé adapté et remplissez votre plan :

    Élément Adresse IP choisie Masque
    Adresse du réseau
    SRV (DHCP + DNS + web)
    PC-LOCAL-1
    PC-LOCAL-2
    PC-LOCAL-3 (en DHCP) première adresse de votre plage DHCP :
    • Rappels avant de choisir (cliquer pour déplier)
      • Les 3 plages privées : 10.x.x.x, 172.16.x.x à 172.31.x.x, 192.168.x.x.
      • L'adresse .0 du réseau et la dernière adresse de diffusion ne sont jamais attribuées à une machine.
      • Convention souvent utilisée : une adresse basse et facile à retenir pour le serveur (au chantier 1 : .10).
      • La plage DHCP ne doit pas recouvrir les IP fixes : commencez-la assez haut (au chantier 1 : .100).

    a) Quelle plage privée avez-vous choisie, et pourquoi celle-là ?
    b) Expliquez en une phrase pourquoi votre plage DHCP ne démarre pas à l'adresse .1.

  2. 2
    Construire la maquette
    • Placer les différents équipements demandé.
  3. 3
    Prouver la communication
    Question 5

    Comment s'assurer que la communication entre les différents poste est bien fonctionelle ?

  4. 4
    Mettre en service DHCP, DNS et le site interne
    • Activez DHCP Server avec votre plage, puis DNS Server avec un enregistrement du nom de votre choix pointant vers le serveur WEB, puis activez le Web Server.

    a) Comment faites vous pour que tout les postes connaissent l'adresse du serveur WEB ?

Chantier 3 — Relier les deux îlots

45 min
Situation

La situation de l'entreprise évolue et votre tuteur vous demande d'ajouter un deuxième local technique à côté du premier : 2 postes supplémentaires (PC-LOCAL-4 et PC-LOCAL-5) qui doivent communiquer avec le premier local et consulter son serveur web. Vous ajoutez donc un routeur entre les deux réseaux.

  1. 1
    Créer le 2ᵉ îlot
    • Dans le fichier du chantier 2 : ajoutez un switch et 2 PC, câblés en étoile.
    • Choisissez un réseau différent pour ce 2ᵉ îlot (autre plage privée que celle du local 1) et attribuez les IP.
    Question 7

    Pourquoi le 2ᵉ îlot doit-il être dans un réseau différent du premier ?

  2. 2
    Câbler et configurer le routeur
    • Placez un Routeur entre les deux switchs et câblez-le vers chacun.
    • Sur le routeur : dans General, cliquez Manage Connections pour ajouter une carte réseau, puis donnez à la première interface une adresse du réseau 1, et à la seconde une adresse du réseau 2.
    • Sur chaque poste : renseignez la passerelle = l'adresse du routeur dans son propre réseau (et le serveur DNS du local 1).
    • Aide : la règle de la passerelle
      • La passerelle est la « porte de sortie » du réseau : elle doit être une adresse du réseau auquel appartient le poste.
      • Un poste du local 1 prend donc l'adresse de l'interface « réseau 1 » du routeur ; un poste du local 2 prend l'autre.
  3. 3
    Tester entre les deux locaux

    Depuis PC-LOCAL-1 :

    N° Commande à taper Mon résultat ✔ / ✘
    1 ping <passerelle du local 1>
    2 ping <passerelle du local 2>
    3 ping <IP de PC-LOCAL-4>
    4 host intranet.local (ou le nom choisi au chantier 2)
    Question 8

    Notez vos observation dans votre compte rendu.

    Le site web du local 1 est-il consultable depuis un poste du local 2 par son nom ?

    Chantier 3

    Schéma final des deux réseaux + routeur (adresses des interfaces), fichier chantier3_deux-ilets.fls.

08

Lexique

Vocabulaire
Mot Définition
Filius Simulateur de réseaux pédagogique : on y construit et teste une maquette avant le câblage réel.
Topologie en étoile Chaque poste est relié par son propre câble à un équipement central (switch).
Switch Envoie chaque trame uniquement sur le bon port, grâce à sa table d'adresses MAC.
Routeur / passerelle Relie des réseaux différents ; c'est la « porte de sortie » de chaque réseau. Une interface par réseau.
Plan d'adressage Document définissant le réseau, le masque et l'attribution des adresses avant l'installation.
Adresse de diffusion (broadcast) Message envoyé à toutes les machines du réseau en même temps.
Bail DHCP Adresse IP attribuée par le serveur DHCP, pour une durée limitée, à un client qui la demande.
APIPA (169.254.x.x) Adresse d'auto-configuration attribuée quand aucun serveur DHCP ne répond : signe de panne DHCP.
Serveur DNS Traduit un nom (intranet.techusine.fr) en adresse IP ; interrogé par host ou nslookup.
Serveur web Machine qui héberge des sites, consultables par URL depuis un navigateur.
