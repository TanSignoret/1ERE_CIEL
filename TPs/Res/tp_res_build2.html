02

Chantier 1 — Implémenter un LAN

Guidé
Situation professionnelle

Lors de votre stage chez Tech'Usine, vous êtes chargé de mettre en service du réseau de l'atelier. Le dossier technique est prêt : appliquez-le exactement, puis prouvez que tout fonctionne.

Le dossier technique

                   ┌──────────────────┐
                   │    SW-ATELIER    │   switch
                   └──┬─────┬────┬───┘
                      │     │    │
            ┌─────────┘     │    └─────────┐
            │               │              │
     ┌──────┴──────┐ ┌──────┴───────┐ ┌────┴────────┐
     │     SRV     │ │ PC-ATELIER-1 │ │ PC-ATELIER-2│
     │192.168.10.10│ │192.168.10.11 │ │             │
     │ IP fixe     │ │ IP Fixe      │ │ IP via DHCP │
     │DHCP+DNS+Web │ │              │ │             │
     └─────────────┘ └──────────────┘ └─────────────┘
     Réseau : 192.168.10.0 · Masque : 255.255.255.0
     DNS : intranet.techusine.fr → 192.168.10.10
Élément Adresse IP Masque Remarque
Réseau de l'atelier 192.168.10.0 255.255.255.0 plage privée
SRV 192.168.10.10 255.255.255.0 IP fixe — DHCP, DNS et web
PC-ATELIER-1 192.168.10.11 255.255.255.0 IP fixe
PC-ATELIER-2 Via DHCP Via DHCP Via DHCP
Plage DHCP (réservée aux futurs postes) .100 à .150 255.255.255.0 activée sur SRV
Nom interne du serveur techusine.fr — enregistrement DNS

À vous de jouer

  1. 1
    Construire la maquette
    • Mode Design : placez le switch (renommez-le SW-ATELIER), 2 portables et 1 serveur, et renommez chaque machine comme précisé.
    • Câblez en étoile, puis passez en mode Simulation.
    • Vérifiez que la communication est bien établie.
    Question 1

    Comment vérifiez-vous que la communication est possible entre les machines ?

  2. 2
    Configurer les adresses fixes

    Retour en mode Design : renseignez les IP du dossier (SRV, PC-ATELIER-1) avec le masque 255.255.255.0.

  3. 3
    Mettre en service DHCP, DNS et web sur SRV
    • DHCP Server : plage 192.168.10.100 à 192.168.10.150, masque 255.255.255.0, DNS 192.168.10.10, puis Activer.
    • Ajoutez le PC-ATELIER-2 avec une attribution de l'IP automatiquement, grâce au DHCP.
    • DNS Server : enregistrement techusine.fr → 192.168.10.10, puis Start.
    • Web Server : lancez-le, puis Start.
    Question 2

    Que devez-vous faire pour vérifier que les différents services sont bien actifs et fonctionnels ?

    Insérez des captures d'écran pour illustrer vos réponses, dans votre compte rendu.

  4. 4
    Prouver que ça communique

    Depuis le Command Line de PC-ATELIER-1, notez le résultat de chaque test :

    N° Commande Résultat attendu Mon résultat ✔ / ✘
    1 ping 192.168.10.12 PC-ATELIER-2 répond
    2 ping 255.255.255.255 toutes les machines répondent
    3 host techusine.fr le DNS renvoie 192.168.10.10
    4 navigateur : http://techusine.fr la page s'affiche par le nom

Chantier 2 — Concevoir et implémenter un LAN

Autonome · Noté
Situation professionnelle

Votre tuteur est satisfaits de votre travail. Il vous demande de préparer le dossier technique pour le LAN administratif.

Ce réseau (pour le moment indépendant), possède :

  • 1 serveur (DHCP + DNS + web)
  • 2 postes, avec des adresses fixes
  • 1 poste en DHCP

  1. 1
    Rédiger votre dossier technique

    Complétez ce tableau dans votre compte rendu — c'est votre plan d'adressage :

    Élément Votre choix Justification (une phrase)
    Adresse du réseau
    Masque
    SRV-ADMIN
    PC-ADMIN-1
    PC-ADMIN-2
    PC-ADMIN-3 (en DHCP)
    Plage DHCP
    Nom interne du serveur

    • Rappels pour bien choisir (cliquer pour déplier)
      • Les 3 plages privées : 10.x.x.x, 172.16.x.x à 172.31.x.x, 192.168.x.x.
      • L'atelier utilise déjà 192.168.10.0/24 : votre réseau administratif devra être différent (on les reliera au chantier 3).
      • .0 (réseau) et la dernière adresse (diffusion) ne sont jamais attribuées.
      • IP fixes basses pour les serveurs ; plage DHCP haute, sans chevaucher les fixes.
    Question 3

    Justifiez vos trois choix principaux :

    • l'adresse du réseau et le masque
    • l'adresse IP fixe du serveur
    • la plage DHCP

  2. 2
    Construire et mettre en service
    • Dans le même fichier Filius (éloignez la maquette de l'atelier sur l'écran)
    • Appliquez votre plan : IP fixes, DHCP avec votre plage, DNS avec votre nom, web sur SRV-ADMIN.

    Faites attention aux noms de vos équipements.

  3. 3
    Prouver que ça communique
    Question 4

    Comment faites-vous pour tester le bon fonctionnement du réseau et de ses services ?

    Insérez des captures d'écran pour illustrer vos réponses, dans votre compte rendu.

    Validation chantier 2

    Le réseau administratif fonctionne conformément à votre dossier, et votre tableau d'adressage est justifié.

04

Chantier 3 - Lier les réseaux

Guidé
Situation

Votre tureur vous demande désormais que l'atelier et l'administratif communiquent : les postes de l'administratif doivent consulter le site interne de l'atelier. On installe un routeur entre les deux réseaux. 

   RÉSEAU ATELIER (votre réseau 1)         RÉSEAU ADMIN (votre réseau 2)
        SW-ATELIER                             SW-ADMIN
            │       ┌────────────┐                │
            └───────┤  ROUTEUR   ├────────────────┘
                    │ if A : ……  │  ← une adresse du RÉSEAU 1
                    │ if B : ……  │  ← une adresse du RÉSEAU 2
                    └────────────┘
  1. 1
    Installer et configurer le routeur
    • Placez un Routeur entre les deux switchs et câblez-le vers chacun.
    • Onglet General → Gérer les connections : ajoutez une 2ᵉ carte réseau. Donnez à la 1ʳᵉ interface une adresse du réseau atelier, à la 2ᵉ une adresse du réseau administratif.
    • Choisissez pour le routeur des adresses libres de chaque plan (en dehors des IP fixes et de la plage DHCP).
  2. 2
    Configurer les passerelles de tous les postes
    • Sur chaque poste et chaque serveur : renseignez la passerelle = l'adresse du routeur dans son propre réseau.
    • Aide : la règle de la passerelle (cliquer pour déplier)
      • La passerelle est la « porte de sortie » du réseau : elle doit être une adresse du réseau auquel appartient le poste.
      • SRV (atelier) → interface « atelier » du routeur. SRV-ADMIN (administratif) → interface « administratif » du routeur.
    Question 5

    SRV (atelier) veut joindre SRV-ADMIN (administratif).

    Quel trajet le message emprunte-t-il ? Quel est le rôle du switch et du routeur dans ce trajet ?

  3. 3
    Tester entre les deux LAN

    Depuis PC-ATELIER-1 :

    N° Commande Résultat attendu Mon résultat ✔ / ✘
    1 ping <passerelle atelier> le routeur répond
    2 ping <passerelle admin> la 2ᵉ interface répond
    3 ping <IP de SRV-ADMIN> SRV-ADMIN répond
    4 navigateur : site web de SRV-ADMIN la page administrative s'affiche

Chantier 4 — Lier deux maquettes

Guidé - Bonus
Situation

Votre tuteur prépare la mise en service réelle du réseau. Avant de câbler pour de vrai, il veut voir une possibilité étonnante de Filius : le composant modem. Un modem possède une vraie interface réseau : il permet de relier deux maquettes Filius, la vôtre et celle d'un camarade, chacune ouverte sur un ordinateur différent (ou deux instances sur le même ordinateur).
Objectif final : lier deux postes, un dans chaque maquette.

   VOTRE Filius (PC du lycée n°1)          FILIUS DU CAMARADE (PC n°2)
   ┌────────────────────────┐              ┌─────────────────────────┐
   │ LAN atelier 192.168.10 │              │ LAN maquette du voisin  │
   │   PC-ATELIER-1         │              │   poste                 │
   │      │                 │              │      │                  │
   │  ┌───┴────┐            │              │  ┌─────┴───┐            │
   │  │ MODEM-1│            │              │  │ MODEM-2 │            │
   │  └───┬────┘            │              │  └─────┬───┘            │
   └──────┼─────────────────┘              └────────┼────────────────┘
          │   vrai réseau du lycée (adresses IP réelles des PC)   │
          └─────────────────────┬─────────────────────────────────┘
                        MODEM-1 ◄──────────────► MODEM-2
              (chaque modem connaît l'IP réelle de l'autre PC + le port)
Avant de commencer

Regardez le tutoriel (4 min) qui montre comment fonctionne le composant modem : Tuto Filius — Composant « Modem ». Vous pouvez le laisser ouvert dans un onglet et refaire les manipulations au fur et à mesure.

  1. 1
    Placer et câbler le modem
    • Dans votre maquette (mode Design) : placez un composant Modem (barre de gauche, catégorie des équipements réseau) et renommez-le MODEM-1.
    • Câblez le modem à un poste de votre maquette (par exemple PC-ATELIER-1).
    • Le camarade fait la même chose de son côté (MODEM-2, câblé à son poste).
  2. 2
    Trouver l'adresse IP réelle de chaque ordinateur
    • Le modem ne communique pas dans la simulation : il utilise le vrai réseau du lycée. Il faut donc l'adresse IP réelle de chaque ordinateur.
    • Sur votre PC : relevez votre adresse IPv4.
  3. 3
    Configurer et lancer la connexion des deux modems
    • Double-clic sur MODEM-1 : saisissez l'adresse IP réelle du PC du camarade et le port de connexion (même valeur des deux côtés, par ex. 55555), puis lancez la connexion.
    • Le camarade fait de même avec votre adresse IP : les deux modems doivent passer « connecté ».
  4. 4
    Bonus — faire communiquer les deux postes
    • Objectif : que PC-ATELIER-1 (votre maquette) communique avec le poste de la maquette du camarade, à travers les deux modems.
    • Pour cela, le poste de chaque côté doit connaître le chemin vers l'autre maquette : renseignez dans la configuration réseau du poste la passerelle adaptée (aide : le modem est la porte de sortie de votre maquette — adressez-vous à lui selon la règle de la passerelle vue au chantier 3).
    Question 6

    Comment faire pour s'assurer que le trafic entre vos deux maquettes circule correctement ?

    Insérez une capture d'écran de la connexion réussie et de la communication, entre les deux maquettes, dans votre compte rendu.
