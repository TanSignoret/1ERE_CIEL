00

Ce que vous allez apprendre

Objectifs

Dans ce TP noté, vous allez travailler en binôme pour :

  • Créer un dépôt Git et y collaborer en ligne de commande.
  • Écrire des scripts Python pour automatiser des tâches simples.
  • Faire chacun 1 commit et 1 push sur le dépôt partagé.
À la fin de la séance, vous devrez m'envoyer le lien de votre dépôt Git.

À la fin de ce TP, vous aurez vu ou revu :

  • Git en ligne de commande pour.
  • Créer un dépôt GitHub et y collaborer.
  • Collaborer sur un fichier Python en utilisant Git.
  • Écrire des scripts Python avec :
    • Des variables.
    • Des entrées/sorties (input(), print()).
    • Des conditions (if/else).
    • Des boucles (for, while).

Matériel nécessaire

Matériel
  • Un PC avec :
    • Accès à Internet.

    • Git installé.
    • Un terminal (ou invite de commandes) pour utiliser Git.

02

Introduction

Contexte

Chez RéseauPro Solutions, votre équipe utilise Git en ligne de commande pour collaborer sur des scripts Python. Votre tuteur vous demande de :

  1. Créer un dépôt Git pour un projet de scripts Python.
  2. Écrire des scripts pour automatiser des tâches d'administration réseau.
  3. Collaborer avec votre binôme pour partager le travail sur le même fichier.
  4. Faire chacun 1 commit et 1 push pour valider votre contribution.

Ce TP est noté. Vous serez évalués sur :

  • Votre code Python.
  • Votre utilisation de Git en ligne de commande (commits, push, collaboration).
  • Votre capacité à travailler en équipe.

03

Étapes du TP

Organisation

Voici les étapes à suivre pour réaliser ce TP.

Chaque binôme doit créer dépôt Git et y collaborer. Git sera utilisé en ligne de commande.

  1. 1
    Configurer l'environnement

    À faire par chaque membre du binôme :

    1. Installer VS Code si ce n'est pas déjà fait.
    2. Installer Git si ce n'est pas déjà fait.
    3. Vérifier que Git est installé en ouvrant un terminal et en tapant : 
      git --version
      Si Git est installé, vous devriez voir un numéro de version (ex: git version 2.40.1).
  2. 2
    Créer un dépôt GitHub
    1. Se connecter sur son compte GitHub (github.com).
    2. Créer un nouveau dépôt (un seul pour le binôme) :
      • Nom : TP_CIEL_Git_Python_[VotreNom1]_[VotreNom2] (ex: TP_CIEL_Git_Python_Dupont_Martin).
      • Description : TP collaboratif sur Git et Python - Première Bac Pro CIEL.
      • Visibilité : Public.
      • Ne pas cocher "Add a README" ou "Add .gitignore".
    3. Ajouter l'autre membre du binôme comme collaborateur :
      • Allez dans Settings → Collaborators.
      • Ajoutez l'email GitHub de votre binôme.
    4. Vérifiez que le dépôt apparaît bien sur vos 2 comptes.
  3. 3
    Cloner le dépôt en local

    À faire par chaque membre du binôme :

    1. Sur la page du dépôt GitHub, cliquez sur "Code" (bouton vert) et copiez l'URL HTTPS.
    2. Ouvrez un terminal (ou l'invite de commandes) et placez-vous dans le dossier où vous voulez cloner le dépôt (ex: cd Documents).
    3. Exécutez la commande suivante pour cloner le dépôt : 
      git clone https://github.com/utilisateur/TP_CIEL_Git_Python_[Nom1]_[Nom2].git
    4. Un dossier TP_CIEL_Git_Python_[Nom1]_[Nom2] est créé. Ouvrez-le dans VS Code.
  4. 4
    Créer le fichier Python et faire un premier commit

    À faire par un seul membre du binôme :

    1. Dans le dossier du dépôt, créez un fichier nommé scripts_reseau.py avec VS Code.
    2. Ajoutez un commentaire en haut du fichier pour indiquer le nom des deux membres du binôme : 
      # TP Git et Python - Binôme : [Nom1] [Prénom1] et [Nom2] [Prénom2]
# Date : [JJ/MM/AAAA]
    3. Ouvrez un terminal git (dans votre dossier) et pousser vos modifications
    Rappel

    • git add [fichier] : Ajoute le fichier en attente.
    • git commit -m "..." : Valide les modifications avec un message.
    • git push : Envoie les modifications sur GitHub (branche main).

  5. 5
    Réaliser les exercices Python

    Chaque membre du binôme doit réaliser 3 ou 4 exercices dans le fichier scripts_reseau.py.

    Repartissez-vous les exercices (ex: un membre fait les exercices 1, 2, 4 et 6, l'autre fait les exercices 3, 5 et 7).

    Chaque exercice doit être dans un commentaire séparé (ex: # Exercice 1 - Réalisé par [Nom1]).

    Consignes pour le code :

    • Utilisez uniquement les fonctions input(), print() et len().
    • Pas de gestion d'erreur.
    • Pas de fonctions complexes (ex: def).

    Voici les exercices à réaliser dans le fichier scripts_reseau.py :

    Exercice 1 : Manipulation de variables

    Créer deux variables ip1 et ip2 avec les valeurs "192.168.1.1" et "10.0.0.1".

    Échanger leurs valeurs (pour que ip1 contienne "10.0.0.1" et ip2 contienne "192.168.1.1").

    Afficher les valeurs finales de ip1 et ip2 avec print().

    Exemple 

    Avant échange : a = 10, b = 20
Après échange : a = 20, b = 10

    Exercice 2 : Entrées/Sorties et manipulation de variable
    • Demande à l'utilisateur de saisir deux nombres entiers (un par un) avec input().
    • Stocke ces nombres dans deux variables : nombre1 et nombre2.
    • Calcule la somme et la moyenne de ces deux nombres.
    • Affiche les résultats sous la forme : 
      La somme de 3 et 5 est 8.
La moyenne de 3 et 5 est 4.
    Rappel

    Pour calculer la moyenne : moyenne = (nombre1 + nombre2) / 2.

    N'oublie pas de convertir les entrées en nombres avec int().

    Exercice 3 : Entrées/Sorties et manipulation de variable

    Demander à l'utilisateur de saisir son prénom et son nom, puis afficher un message de bienvenue avec print(). La sortie doit afficher : 

    >> Quel est ton nom ?_
>> Quel est ton prénom ?_
>> Bonjour, Thomas Jolly !

    Le caractère _ corresponds à un espace avant le curseur.

    Dans le cas de cet exemple l'utilisateur aura tapé Jolly à la question quel est ton nom et Thomas à la question quel est ton prénom.

    Exercice 4 : Conditions

    Demander à l'utilisateur de saisir son âge (en tant que str), le convertir en int, puis afficher :

    • "Accès autorisé." si l'âge est supérieur ou égal à 18.
    • "Accès refusé." sinon.

    Exercice 5 : Conditions

    Demander à l'utilisateur de saisir un mot de passe, puis afficher :

    • "Mot de passe valide." si le mot de passe contient au moins 8 caractères.
    • "Mot de passe invalide." sinon.
    Utilisez len() pour vérifier la longueur.

    Exercice 6 : Boucles

    Utiliser une boucle for pour afficher les 10 premiers nombres pairs (de 0 à 18).

    Exercice 7 : Boucles

    Demander à l'utilisateur de saisir un nombre (en tant que str), le convertir en int : nombre_int = int(nombre_str)

    Afficher la table de multiplication de ce nombre (de 1 à 10) avec une boucle for. Exemple : Si l'utilisateur saisi 5, le script doit afficher : 

    Table de 5 :
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
  6. 6
    Faire des commits et pushes en ligne de commande

    À faire par chaque membre du binôme :

    1. Ouvrez un terminal dans le dossier du dépôt.
    2. Vérifiez que vos modifications (votre partie du code) sont bien présentes dans le fichier scripts_reseau.py.
    3. Exécutez les commandes pour ajouter vos modifications, faire un commit et pousser sur GitHub
    ⚠️ Important

    Avant de faire un git push, faites toujours un git pull pour récupérer les dernières modifications de votre binôme

    Cela évite les conflits.

  7. 7
    Vérifier le dépôt GitHub

    À faire par les deux membres du binôme :

    1. Rafraîchissez la page du dépôt GitHub.
    2. Vérifiez que :
      • Le fichier scripts_reseau.py contient bien tous les exercices.
      • Les deux membres du binôme ont chacun fait 1 commit.
      • Le code est fonctionnel et bien commenté.
    Livrable

    Envoyez le lien du dépôt GitHub à votre professeur par mail. Format du mail :

    • Objet : TP Git/Python - [Nom1]_[Nom2]
    • Contenu : Lien vers le dépôt GitHub.

Aide

📌 Commandes Git de base

Voici les commandes Git essentielles pour ce TP :

Action Commande Description
Cloner un dépôt git clone https://github.com/utilisateur/repo.git Copie un dépôt distant en local.
Voir l'état git status Affiche les fichiers modifiés, ajoutés ou non suivis.
Ajouter un fichier git add fichier.py Ajoute un fichier à l'index (staging area).
Ajouter tous les fichiers git add . Ajoute tous les fichiers modifiés/nouveaux à l'index.
Faire un commit git commit -m "Message" Valide les modifications avec un message.
Pousser sur GitHub git push origin main Envoie les commits locaux vers GitHub (branche main).
Récupérer les modifications git pull origin main Récupère les dernières modifications du dépôt distant.
Voir l'historique git log Affiche l'historique des commits.

📌 Comment résoudre les problèmes courants ?

Problème Cause possible Solution
git: command not found Git n'est pas installé. Installez Git depuis git-scm.com.
fatal: not a git repository Vous n'êtes pas dans un dépôt Git. Placez-vous dans le dossier du dépôt avec cd.
fatal: 'origin' does not appear to be a git repository Le dépôt distant n'est pas configuré. Vérifiez que vous avez bien cloné le dépôt avec git clone.
Updates were rejected because the remote contains work you do not have locally Conflit de merge. Faites un git pull origin main avant de pousser.
Je ne vois pas mes modifications sur GitHub. Oubli de git add ou git commit. Vérifiez avec git status et refaites les étapes.
