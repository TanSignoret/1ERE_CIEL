1. Calculer la moyenne de 5 temps de réponse réseau

Contexte : Les élèves doivent calculer la moyenne de 5 temps de réponse réseau pour RéseauPro Solutions.

Objectifs pédagogiques :

  • Utiliser des boucles for pour demander plusieurs entrées.
  • Gérer les erreurs de saisie avec try/except.
  • Calculer une moyenne à partir d'une liste de valeurs.
Solution 
# Exercice 1 : Calculer la moyenne de 5 temps de réponse réseau
# Contexte : RéseauPro Solutions - Automatisation des calculs de performance

# Initialisation d'une liste pour stocker les temps de réponse
temps_reponse = []

# Demander à l'utilisateur de saisir 5 temps de réponse
for i in range(5):
    while True:
        try:
            temps = float(input(f"Saisir le temps de réponse {i + 1} (en ms) : "))
            temps_reponse.append(temps)
            break  # Sortir de la boucle si la saisie est valide
        except ValueError:
            print("Erreur : veuillez saisir un nombre valide.")

# Calculer la moyenne
moyenne = sum(temps_reponse) / len(temps_reponse)

# Afficher le résultat
print(f"Moyenne des temps de réponse : {moyenne:.2f} ms")
Explications

  • temps_reponse = [] : Initialise une liste vide pour stocker les temps de réponse.
  • for i in range(5): : Boucle pour demander 5 valeurs à l'utilisateur.
  • while True: : Boucle infinie pour gérer les erreurs de saisie.
  • try/except ValueError: : Attrape les erreurs si l'utilisateur saisi un texte au lieu d'un nombre.
  • moyenne = sum(temps_reponse) / len(temps_reponse) : Calcule la moyenne.
  • print(f"Moyenne des temps de réponse : {moyenne:.2f} ms") : Affiche la moyenne avec 2 décimales.

Conseils pédagogiques

  • Si les élèves bloquent sur la boucle while True:, leur montrer comment sortir de la boucle avec break.
  • Leur demander de tester avec des valeurs simples (ex: 10, 20, 30, 40, 50) pour vérifier que la moyenne est correcte.
  • Expliquer que :.2f dans le print permet d'afficher 2 décimales.

2. Vérifier un mot de passe

Contexte : Les élèves doivent vérifier si un mot de passe respecte les règles de sécurité de RéseauPro (8 caractères minimum + 1 chiffre).

Objectifs pédagogiques :

  • Utiliser des conditions if/else.
  • Vérifier la longueur d'une chaîne avec len().
  • Utiliser any() pour vérifier la présence d'un chiffre.
Solution 
# Exercice 2 : Vérifier un mot de passe
# Contexte : RéseauPro Solutions - Sécurité des comptes utilisateurs

# Demander le nom d'utilisateur et le mot de passe
nom_utilisateur = input("Saisir votre nom d'utilisateur : ")
mot_de_passe = input("Saisir votre mot de passe : ")

# Vérifier les conditions
mot_de_passe_valide = len(mot_de_passe) >= 8 and any(char.isdigit() for char in mot_de_passe)

# Afficher le résultat
if mot_de_passe_valide:
    print(f"Accès autorisé pour {nom_utilisateur}")
else:
            print(f"Accès refusé pour {nom_utilisateur}")
Explications

  • len(mot_de_passe) >= 8 : Vérifie que le mot de passe a au moins 8 caractères.
  • any(char.isdigit() for char in mot_de_passe) : Vérifie qu'au moins un caractère est un chiffre.
  • mot_de_passe_valide = ... : Stocke le résultat de la vérification dans une variable booléenne.
  • if mot_de_passe_valide: : Affiche un message en fonction du résultat.

Conseils pédagogiques

  • Expliquer que any() retourne True si au moins un élément de la liste est vrai.
  • Montrer comment tester la fonction avec des mots de passe valides et invalides :
    • Pass123 → Accès autorisé.
    • Pass → Accès refusé (trop court).
    • Password → Accès refusé (pas de chiffre).
  • Leur demander d'ajouter une vérification pour les majuscules (ex: any(char.isupper() for char in mot_de_passe)).

3. Simuler un ping

Contexte : Les élèves doivent simuler un test de connectivité (ping) vers 10 adresses IP (192.168.1.1 à 192.168.1.10). Le ping réussit si l'IP est paire.

Objectifs pédagogiques :

  • Utiliser une boucle for pour parcourir une plage de valeurs.
  • Générer des adresses IP dynamiquement avec des f-strings.
  • Utiliser l'opérateur modulo % pour vérifier si un nombre est pair.

# Exercice 3 : Simuler un ping
# Contexte : RéseauPro Solutions - Test de connectivité réseau

# Parcourir les adresses IP de 1 à 10
for i in range(1, 11):
    ip = f"192.168.1.{i}"

    # Vérifier si l'IP est paire (i % 2 == 0)
    if i % 2 == 0:
        print(f"Ping réussi vers {ip}")

Explications

  • for i in range(1, 11): : Boucle de 1 à 10 (inclus).
  • ip = f"192.168.1.{i}" : Génère une adresse IP dynamique (ex: 192.168.1.1, 192.168.1.2, etc.).
  • i % 2 == 0 : Vérifie si i est pair (le reste de la division par 2 est 0).

Conseils pédagogiques

  • Expliquer que range(1, 11) génère les nombres de 1 à 10 (11 non inclus).

Objectifs pédagogiques :

  • Gérer les erreurs de saisie avec try/except.

# Exercice 4 : Analyser des valeurs de bandwith
# Contexte : RéseauPro Solutions - Surveillance du réseau

# Initialisation d'une liste pour stocker les valeurs de bandwith
valeurs_bandwith = []

# Demander à l'utilisateur de saisir 10 valeurs de bandwith
for i in range(10):
    while True:
        try:
            valeur = float(input(f"Saisir la valeur de bandwith {i + 1} (en Mbps) : "))
            valeurs_bandwith.append(valeur)
            break
        except ValueError:
            print("Erreur : veuillez saisir un nombre valide.")

# Calculer les statistiques
valeur_max = max(valeurs_bandwith)
valeur_min = min(valeurs_bandwith)
moyenne = sum(valeurs_bandwith) / len(valeurs_bandwith)

# Afficher les résultats
print(f"Valeur maximale : {valeur_max} Mbps")
print(f"Valeur minimale : {valeur_min} Mbps")
print(f"Moyenne : {moyenne:.2f} Mbps")
Explications

  • valeurs_bandwith = [] : Initialise une liste vide pour stocker les valeurs.
  • for i in range(10): : Boucle pour demander 10 valeurs.
  • try/except ValueError: : Gère les erreurs si l'utilisateur saisi un texte.
  • max(valeurs_bandwith) : Trouve la valeur maximale.
  • min(valeurs_bandwith) : Trouve la valeur minimale.
  • sum(valeurs_bandwith) / len(valeurs_bandwith) : Calcule la moyenne.

Conseils pédagogiques

  • Expliquer que max(), min(), et sum() sont des fonctions intégrées de Python.
  • Leur demander de tester avec des valeurs simples (ex: 10, 20, ..., 100) pour vérifier les résultats.
  • Leur montrer comment trier la liste avec valeurs_bandwith.sort().

1. Valider une adresse IP

Contexte : Créer une fonction pour valider les adresses IP saisies par les utilisateurs chez RéseauPro.

Objectifs pédagogiques :

  • Créer une fonction avec des paramètres et une valeur de retour.
  • Utiliser isinstance() pour vérifier le type d'une variable.
  • Gérer les erreurs avec raise ValueError.
  • Documenter une fonction avec une docstring.
Solution 
def valider_ip(ip):
    """
    Valide une adresse IP au format xxx.xxx.xxx.xxx.

    Args:
        ip (str): Adresse IP à valider.

    Returns:
        bool: True si l'IP est valide, False sinon.

    Raises:
        ValueError: Si ip n'est pas une chaîne de caractères.
    """
    # Vérifier que ip est une chaîne de caractères
    if not isinstance(ip, str):
        raise ValueError("IP invalide : doit être une chaîne de caractères.")

    # Diviser l'IP en parties
    parties = ip.split('.')

    # Vérifier qu'il y a exactement 4 parties
    if len(parties) != 4:
        return False

    # Vérifier que chaque partie est un nombre entre 0 et 255
    for partie in parties:
        try:
            nombre = int(partie)
            if nombre < 0 or nombre > 255:
                return False
        except ValueError:
            return False

    return True

# Script principal pour tester la fonction
if __name__ == "__main__":
    ip = input("Saisir une adresse IP : ")
    try:
        if valider_ip(ip):
            print("IP valide")
        else:
            print("IP invalide")
    except ValueError as e:
        print(f"Erreur : {e}")
Explications

  • def valider_ip(ip): : Déclare une fonction avec un paramètre ip.
  • isinstance(ip, str) : Vérifie que ip est une chaîne de caractères.
  • raise ValueError("...") : Lève une exception si ip n'est pas une chaîne.
  • ip.split('.') : Divise l'IP en parties en utilisant le point comme séparateur.
  • for partie in parties: : Parcourt chaque partie de l'IP.
  • int(partie) : Convertit chaque partie en entier.
  • if nombre < 0 or nombre > 255: : Vérifie que chaque partie est entre 0 et 255.

Conseils pédagogiques

  • Expliquer que raise ValueError permet de lever une exception si une condition n'est pas respectée.
  • Leur demander de tester la fonction avec des IP valides et invalides :
    • 192.168.1.1 → Valide.
    • 256.1.1.1 → Invalide (256 > 255).
    • 192.168.1 → Invalide (3 parties au lieu de 4).
    • 123 (entier) → Erreur (n'est pas une chaîne).
  • Leur montrer comment améliorer la fonction pour accepter des IP au format CIDR (ex: 192.168.1.0/24).

2. Générer un mot de passe

Contexte : Créer une fonction pour générer des mots de passe robustes pour RéseauPro.

Objectifs pédagogiques :

  • Utiliser le module random pour générer des valeurs aléatoires.
  • Utiliser string.ascii_letters et string.digits pour définir des caractères possibles.
  • Gérer les paramètres par défaut (ex: longueur=12).
  • Lever des exceptions pour les entrées invalides.
Solution 
import random
import string

def generer_mot_de_passe(longueur=12):
    """
    Génère un mot de passe aléatoire avec majuscules, minuscules, chiffres et symboles.

    Args:
        longueur (int): Longueur du mot de passe (par défaut : 12).

    Returns:
        str: Mot de passe généré.

    Raises:
        ValueError: Si longueur < 8.
    """
    # Vérifier la longueur minimale
    if longueur < 8:
        raise ValueError("Longueur minimale : 8")

    # Définir les caractères possibles
    caracteres = string.ascii_letters + string.digits + "!@#$%^&*"

    # Générer le mot de passe
    mot_de_passe = ''.join(random.choice(caracteres) for _ in range(longueur))

    return mot_de_passe

# Script principal pour tester la fonction
if __name__ == "__main__":
    try:
        longueur = int(input("Saisir la longueur du mot de passe (par défaut : 12) : ") or 12)
        mot_de_passe = generer_mot_de_passe(longueur)
        print(f"Mot de passe généré : {mot_de_passe}")
    except ValueError as e:
        print(f"Erreur : {e}")
Explications

  • import random, string : Importe les modules nécessaires.
  • longueur=12 : Paramètre par défaut (12 caractères).
  • if longueur < 8: : Vérifie que la longueur est d'au moins 8.
  • string.ascii_letters : Contient toutes les lettres (majuscules + minuscules).

    if longueur < 8:
        raise ValueError("Longueur minimale : 8")

    majuscules = string.ascii_uppercase
    minuscules = string.ascii_lowercase
    chiffres = string.digits
    symboles = "!@#$%^&*"

    mot_de_passe = [
        random.choice(majuscules),
        random.choice(minuscules),
        random.choice(chiffres),
        random.choice(symboles)
    ]

    # Compléter avec des caractères aléatoires
    caracteres = majuscules + minuscules + chiffres + symboles
    mot_de_passe += random.choices(caracteres, k=longueur - 4)

    # Mélanger les caractères
    random.shuffle(mot_de_passe)

    return ''.join(mot_de_passe)

def analyser_logs(fichier):
    """
    Analyse un fichier de logs et retourne des statistiques.

    Args:
        fichier (str): Chemin vers le fichier de logs.

    Returns:
        dict: Dictionnaire avec le nombre total de lignes et le nombre de lignes par niveau.

    Raises:
        FileNotFoundError: Si le fichier n'existe pas.
    """
    try:
        with open(fichier, 'r') as f:
            lignes = f.readlines()
    except FileNotFoundError:
        raise FileNotFoundError(f"Le fichier {fichier} n'existe pas.")

    # Initialiser les compteurs
    statistiques = {
        "total": len(lignes),
        "niveaux": {
            "ERROR": 0,
            "WARNING": 0,
            "INFO": 0
        }
    }

    # Compter les lignes par niveau
    for ligne in lignes:
        if "ERROR" in ligne:
            statistiques["niveaux"]["ERROR"] += 1
        elif "WARNING" in ligne:
            statistiques["niveaux"]["WARNING"] += 1
        elif "INFO" in ligne:
            statistiques["niveaux"]["INFO"] += 1

    return statistiques

# Script principal pour tester la fonction

        resultats = analyser_logs(fichier_logs)
        print(f"Statistiques des logs : {resultats}")
    except FileNotFoundError as e:
        print(f"Erreur : {e}")

Contexte : Refactoriser l'Exercice 3 du TP 1 (simulateur de ping) en utilisant des fonctions pour le rendre plus modulaire.

Solution 
def generer_ips(debut, fin):
    """
    Génère une liste d'adresses IP de 192.168.1.debut à 192.168.1.fin.

    Args:
        debut (int): Première IP (ex: 1).
        fin (int): Dernière IP (ex: 10).

    Returns:
        list: Liste des adresses IP (ex: ["192.168.1.1", "192.168.1.2", ...]).
    """
    return [f"192.168.1.{i}" for i in range(debut, fin + 1)]

def simuler_ping(ip):
    """
    Simule un ping vers une adresse IP.

    Args:
        ip (str): Adresse IP à pinger (ex: "192.168.1.1").

    Returns:
        bool: True si le ping réussit (IP paire), False sinon.
    """
    # Extraire le dernier octet de l'IP
    dernier_octet = int(ip.split('.')[-1])
    return dernier_octet % 2 == 0

def afficher_resultats(ips):
    """
    Affiche les résultats des pings pour une liste d'IPs.

    Args:
        ips (list): Liste des adresses IP à pinger.
    """
    for ip in ips:
        if simuler_ping(ip):
            print(f"Ping réussi vers {ip}")
        else:
            print(f"Ping échoué vers {ip}")

# Script principal
if __name__ == "__main__":
    # Générer les IPs de 1 à 10
    ips = generer_ips(1, 10)

    # Afficher les résultats
    afficher_resultats(ips)
Explications

  • def generer_ips(debut, fin): : Génère une liste d'IPs dynamiquement.
  • [f"192.168.1.{i}" for i in range(debut, fin + 1)] : Utilise une compréhension de liste pour créer la liste.
  • def simuler_ping(ip): : Vérifie si une IP est paire.
  • ip.split('.')[-1] : Extrait le dernier octet de l'IP.
  • def afficher_resultats(ips): : Affiche les résultats pour toutes les IPs.
  • if __name__ == "__main__": : Permet d'exécuter le script uniquement s'il est lancé directement (pas s'il est importé).

Conseils pédagogiques

  • Expliquer que la refactorisation consiste à découper le code en fonctions pour le rendre plus lisible et maintenable.
  • Leur demander de tester chaque fonction séparément :
