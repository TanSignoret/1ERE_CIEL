Ma première page web

Ce que vous allez apprendre

03

Activité 1 — Installer le serveur et décoder le HTML

Guidé

Objectif de la phase : mettre en route votre serveur, puis décortiquer une page HTML avant d'écrire la vôtre.

  1. 1
    Installer le serveur web Ubuntu

    Importez la VM fournie dans les ressources, vérifiez qu'elle est en accès par pont, puis démarrez-la. Vous avez fait tout cela en séance 3 : cette fois, la liste des commandes est fournie sans explication — vous devez savoir expliquer chacune.

    sudo apt update
sudo apt install apache2 -y
systemctl status apache2
ss -tlnp | grep apache
sudo ufw allow 80/tcp
sudo ufw enable
ip a

    Vérifiez depuis le navigateur du poste Windows : la page par défaut d'Apache s'affiche à l'adresse IP de votre VM. Relevez cette adresse dans votre compte rendu.

    Question 1

    Pour chaque commande ci-dessus, indiquez en une phrase ce qu'elle fait. Pourquoi apt update doit-il précéder apt install ?

  2. 2
    Découvrir la page fournie

    Téléchargez exemple_page.html depuis les ressources de la séance, puis affichez-la deux fois :

    • dans le navigateur : ce que voit l'utilisateur ;
    • dans l'éditeur de texte : ce que voit le navigateur, c'est-à-dire le code.

    Ouvrez aussi les outils de développement (F12 → onglet Elements) : c'est la même structure, présentée de façon interactive.

    Question 2

    Dans le navigateur, le texte s'affiche-t-il avec des chevrons <…> ? Que fait le navigateur des balises ?

  3. 3
    Annoter la structure

    Dans l'éditeur de texte, annotez la page (commentaires <!-- … --> ou surlignage + légende dans votre compte rendu) :

    • Entourez la balise <!DOCTYPE html> et notez à quoi elle sert.
    • Repérez les deux grandes parties du document : <head> et <body>. Que contient chacune ?
    • Repérez dans le <head> : <title> et la balise <meta charset>.
    • Repérez dans le <body> : les balises de titres (h1, h2…), de paragraphe (p), de lien (a) et d'image (img).
    • Où se cache l'adresse du lien ou de l'image ?
      • Dans le code de la balise : <a href="…"> et <img src="…">. Notez ces deux modèles, ils vous serviront tels quels en activité 2.
      • Ce fonctionnement détaillé (les « attributs ») sera étudié en profondeur dans un prochain TP : aujourd'hui, recopiez simplement les modèles.
    Question 3

    1. Quelle est la différence entre le <head> et le <body> ? Où s'affiche le contenu du <title> dans le navigateur ?

    2. Quelle est la différence entre <h1> et <h2> ? Peut-on commencer une page directement par un <h3> ? Pourquoi est-ce une mauvaise pratique de structure ?

04

Activité 2 — Rédiger sa page personnelle

Objectif de la phase : écrire votre page. La structure est imposée ; le contenu, les mots et les images sont les vôtres. Les balises ne sont plus données une par une : utilisez la page annotée et l'aide-mémoire en fin de TP.

Sujet

Une page de présentation personnelle : qui êtes-vous, vos passions, votre projet professionnel (après le bac CIEL : poursuite d'études, métier visé, pourquoi ce métier).

  1. 1
    Écrire la structure de base

    Dans l'éditeur de texte, créez le fichier index.html avec la structure imposée ci-dessous. Le contenu des … est à écrire par vous :

    <!DOCTYPE html>
<html lang="fr">
    <head>
        <meta charset="UTF-8">
        <title>…</title>
    </head>
    <body>
        … tout le contenu visible de votre page …
    </body>
</html>
    • À quoi sert <meta charset="UTF-8"> ?
      • À indiquer l'encodage des caractères. Sans lui, les accents (é, è, à…) peuvent s'afficher comme des symboles bizarres : « Ã© » au lieu de « é ».
      • L'enregistrez bien votre fichier en UTF-8 dans l'éditeur (Encodage → UTF-8).
  2. 2
    Rédiger le contenu imposé

    Votre page doit contenir (dans cet ordre) :

    N° Élément exigé Balisage attendu
    1 Un titre principal : votre prénom et nom <h1>
    2 Un court paragraphe « Qui suis-je » <p>
    3 Un titre de section « Mes passions » + au moins 2 paragraphes <h2> + <p>
    4 Un titre de section « Mon projet professionnel » + 1 paragraphe <h2> + <p>
    5 Une image en rapport avec une passion <img src="photo.jpg"> (recopiez le modèle)
    6 Un lien vers un site utile à votre projet (école, métier, fiche ROM…) <a href="https://…">texte du lien</a>
    7 Un lien de contact (votre adresse mail du lycée) <a href="mailto:…">…</a>
    Question 4

    Pourquoi l'image doit-elle être enregistrée dans le même dossier que index.html ? Que se passerait-il si vous la déplaciez après coup ?

  3. 3
    Tester au fur et à mesure

    Enregistrez et testez souvent : à chaque étape, enregistrez le fichier et rechargez le navigateur (Ctrl + F5). N'écrivez jamais 50 lignes d'un coup.

    • Ouvrez votre fichier localement : file:///C:/…/index.html ou un simple double-clic.
    • Vérifiez à chaque fois : le titre de l'onglet, les accents, les images, les liens.
    Question 5

    Quand une image ne charge pas, quel code de statut observez-vous dans l'onglet Réseau ? Le serveur qui héberge l'image est-il « en panne » ? Reliez votre réponse à la séance 1.

  4. 4
    Contrôler sa page

    Avant de publier, vérifiez point par point cette liste de contrôle :

    • Le titre de l'onglet affiche bien votre titre (il est écrit dans le <head>).
    • Les accents s'affichent correctement (sinon : balise <meta charset="UTF-8"> et encodage du fichier en UTF-8).
    • Les 7 éléments exigés du tableau sont tous présents, dans l'ordre.
    • Toutes les balises ouvertes sont fermées, dans le bon ordre (on ferme la dernière balise ouverte en premier).
    • L'image s'affiche et les deux liens fonctionnent.
  5. 5
    Publier sur votre serveur

    Déposez index.html (et votre image) à la racine de votre serveur Ubuntu, comme en séance 3 — la méthode vous appartient : ligne de commande wget, dossier partagé ou copier-coller, à vous de choisir celle que vous savez justifier :

    sudo wget … -O /var/www/html/index.html
ls -l /var/www/html

    Vérifications finales :

    • Votre page s'affiche à l'adresse IP de votre VM.
    • Le poste de votre voisin affiche votre page à cette même adresse.

08

Lexique

Vocabulaire
Mot Définition
HTML HyperText Markup Language : langage de description des pages web, basé sur des balises.
Balise (élément) Marqueur qui décrit la nature du contenu : <p> paragraphe, <h1> titre… La plupart vont par paire ouvrante/fermante.
<head> Partie « administrative » du document : titre de l'onglet, encodage, métadonnées. Non affichée dans la page.
<body> Partie visible du document : tout ce que l'utilisateur voit s'affiche ici.
Imbrication Ordre des balises : la dernière balise ouverte doit être fermée en premier (jamais de croisement).
Encodage UTF-8 Norme d'encodage des caractères qui permet d'afficher accents et symboles correctement.
