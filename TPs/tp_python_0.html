  1. 1
    Mission 1 — La carte de visite du technicien
    Contexte pro

    C'est votre première journée de stage au support technique de RéseauPro Solutions. Votre tutrice, Mme Bertrand, reçoit jusqu'à 40 appels par jour, et à chaque fois elle recopie à la main le nom du technicien et le numéro de poste sur un papier. Elle vous demande : « Tu ne pourrais pas me faire un petit programme qui fabrique la carte de visite tout seul ? »

    Votre mission : livrer le script mission1.py qui fabrique la carte à partir des saisies de l'utilisateur.

    Étape 1.1 — Ouvrez un fichier mission1.py et copiez-collez :

    print("=== RéseauPro Solutions ===")
print("Hotline niveau 1")

    🖥️ Écran attendu :

    === RéseauPro Solutions ===
Hotline niveau 1

    Étape 1.2 — On range maintenant le nom dans une variable. Copiez-collez à la suite :

    technicien = "Paul"
print("Technicien : " + technicien)

    🖥️ Écran attendu (ligne supplémentaire) :

    Technicien : Paul

    Étape 1.3 — Le + colle deux textes. Changez la valeur de technicien par votre prénom et relancez : l'affichage doit suivre tout seul. La boîte technicien a changé de contenu, le print n'a pas bougé.

    Étape 1.4 — Maintenant, on demande le nom à l'utilisateur. La fonction input permet de récupérer une saisie clavier :

    technicien = input("Nom du technicien ? ")

    Les caractères tapés après la question seront alors sauvegardés dans la variable technicien. Dans le terminal cela donne :

    >> Nom du technicien ? Thomas

    La valeur Thomas est donc stockée dans la variable technicien.

    Remplacez la ligne de l'étape 1.2 par cette ligne, et gardez le print dessous. Testez !

    Étape 1.5 — Ajoutez une question pour le numéro de poste, puis affichez la carte complète :

    Résultat attendu 
    >> Nom du technicien ? Léa
>> Numero de poste ? 214
Carte : Léa / poste 214

    ✏️ À toi de jouer : ajoutez une question Site ? et affichez Carte : Léa / poste 214 / site Lyon (le site doit venir de la variable, pas être écrit en dur !).

    Résultat attendu

    Le script pose les 3 questions et affiche une carte complète avec les valeurs saisies.

    >> Nom du technicien ? Léa
>> Numero de poste ? 214
>> Quel est le site ? Lyon
=== RéseauPro Solutions ===
Carte : Léa | Poste 214 | Site : Lyon
  2. 2
    Mission 2 — Le convertisseur de débits
    Contexte pro

    Le commercial M. Diallo vous appelle en panique : il doit envoyer un devis à un client, mais les offres de RéseauPro Solutions sont en mégabits (Mb) alors que le client travaille en kilobits (kb) et en gigabits (Gb). Il vous passe les débits au téléphone, un par un, et il faudrait convertir sans se tromper : 1 Mb = 1000 kb, et 1000 Mb = 1 Gb.

    Votre mission : livrer le convertisseur mission2.py qui affiche les conversions correctes pour n'importe quel débit saisi.

    Étape 2.1 — Copiez-collez dans mission2.py :

    debit = 8
print(str(debit) + " Mb = " + str(debit * 1000) + " kb")

    🖥️ Écran attendu :

    8 Mb = 8000 kb

    Étape 2.2 — Attention, gros piège : remplacez la 1re ligne par :

    debit = input("Débit en Mb ? ")   # on tape 8
print(debit * 1000)

    Lancez… ça ne marche pas (ou ça affiche 888... sans fin). Pourquoi ? Parce que input() range du texte ("8"), pas un nombre. Multiplier du texte par 1000 le répète 1000 fois !

    Étape 2.3 — La solution : convertir le texte en nombre entier avec int() :

    debit = int(input("Débit en Mb ? "))
print(str(debit) + " Mb = " + str(debit * 1000) + " kb")

    🖥️ Écran attendu :

    >> Débit en Mb ? 8
8 Mb = 8000 kb

    Remarquez : int() sert à entrer un nombre, str() sert à le ressortir collé à du texte.

    ✏️ À toi de jouer : ajoutez la conversion vers les gigabits (1 Gb = 1000 Mb) sur le même modèle : 8 Mb = 0.008 Gb. Attention à la division : debit / 1000 donne un nombre à virgule, pas besoin de le convertir davantage.

    Exemple 
    >> Débit en Mb ? 8
8 Mb = 8000 kb
8 Mb = 0.008 Gb
    Validation

    Le script fonctionne avec n'importe quelle valeur saisie (essayez 25, 100, 3).

  3. 3
    Mission 3 — Le contrôle de latence
    Contexte pro

    La nuit dernière, le serveur SRV-WEB d'un client a été saturé sans que personne ne s'en aperçoive. Le chef d'équipe, M. Roux, a analysé l'incident : la latence dépassait 100 ms et personne n'a réagi. Il a décidé de nouvelles règles : au-delà de 100 ms, on déclenche une alerte ; entre 50 et 100 ms, on met le serveur sous surveillance ; en dessous, tout est normal. Il vous confie le tri : « Les techniciens vérifient les latences au tableau, à la main. Automatise-moi ça. »

    Votre mission : livrer le script mission3.py qui affiche le bon verdict pour n'importe quelle latence saisie.

    Étape 3.1 — Copiez-collez dans mission3.py :

    latence = int(input("Temps de réponse en ms ? "))

if latence > 100:
    print("ALERTE : latence trop élevée !")
else:
    print("Latence normale.")

    🖥️ Écran attendu avec 150, puis avec 40 :

    >> Temps de réponse en ms ? 150
ALERTE : latence trop élevée !

>> Temps de réponse en ms ? 40
Latence normale.
    Rappel — les 2 règles d'or du if

    1. Les deux-points : à la fin de la ligne if.
    2. Quatre espaces d'indentation devant tout ce qui est « à l'intérieur » du if ou du else. Sans indentation, Python refuse de démarrer.

    Étape 3.2 — Testez la valeur exacte 100. Que se passe-t-il ? Latence normale. car 100 n'est pas strictement supérieur à 100. La comparaison est >, pas >=.

    Étape 3.3 — On ajoute un niveau intermédiaire avec elif (sinon si). Remplacez tout le bloc if/else par :

    if latence > 100:
    print("ALERTE : latence trop élevée !")
elif latence > 50:
    print("Mise en surveillance du serveur.")
else:
    print("Latence normale.")

    🖥️ Écran attendu avec 75 :

    >> Temps de réponse en ms ? 75
Mise en surveillance du serveur.

    L'ordre est important : Python teste if d'abord, puis elif, et le else attrape tout le reste.

    ✏️ À toi de jouer : une latence négative est impossible (capteur débranché). Ajoutez un test avant les autres qui affiche ERREUR CAPTEUR : valeur impossible. quand latence < 0. Indice : un seul if avec un else suffit, ou ajoutez ce test comme premier if imbriqué.

    Exemple 
    >> Temps de réponse en ms ? -5
ERREUR CAPTEUR : valeur impossible.
    Validation

    Votre script donne la bonne réponse pour -5, 40, 75 et 150. Testez les 4 !

  4. 4
    Mission 4 — La ronde des serveurs
    Contexte pro

    Chaque nuit à 2h, l'équipe d'exploitation doit « pinguer » les serveurs des clients pour vérifier qu'ils répondent vite. Ce travail est fait à la main, ligne par ligne, et la nuit dernière, le technicien de garde s'est endormi avant la fin de la ronde… Mme Bertrand veut vous tester : « Si tu me fais un programme qui enchaîne la ronde tout seul, qui relève les latences une par une et qui compte les alertes, je te confie la supervision de nos plus gros clients. »

    Votre mission : livrer le script mission4.py qui interroge tous les serveurs et affiche le bilan de la ronde (nombre d'alertes).

    Étape 4.1 — Copiez-collez dans mission4.py :

    for i in range(5):
    print("Ping du serveur " + str(i + 1) + " ... OK")

    🖥️ Écran attendu :

    Ping du serveur 1 ... OK
Ping du serveur 2 ... OK
Ping du serveur 3 ... OK
Ping du serveur 4 ... OK
Ping du serveur 5 ... OK

    À lire : « pour i allant de 0 à 4, faire le print ». La boucle tourne 5 fois et i vaut successivement 0, 1, 2, 3, 4 (jamais 5 !). D'où le i + 1 pour afficher 1 à 5.

    Étape 4.2 — Remplacez tout par :

    for i in range(3):
    latence = int(input("Latence du serveur " + str(i + 1) + " ? "))
    if latence > 100:
        print("Serveur " + str(i + 1) + " : HORS LIMITE")
    else:
        print("Serveur " + str(i + 1) + " : OK")

    🖥️ Écran attendu :

    >> Latence du serveur 1 ? 20
Serveur 1 : OK
>> Latence du serveur 2 ? 120
Serveur 2 : HORS LIMITE
>> Latence du serveur 3 ? 55
Serveur 3 : OK

    Observez l'indentation : tout ce qui est répété (question + if) a 4 espaces ; l'intérieur du if en a 8.

    Étape 4.3 — On garde un souvenir de la tournée avec un compteur : une variable qui part de 0 et augmente de 1 à chaque alerte :

    alertes = 0

for i in range(3):
    latence = int(input("Latence du serveur " + str(i + 1) + " ? "))
    if latence > 100:
        print("Serveur " + str(i + 1) + " : HORS LIMITE")
        alertes = alertes + 1
    else:
        print("Serveur " + str(i + 1) + " : OK")

print("Bilan de la ronde : " + str(alertes) + " alerte(s)")

    🖥️ Écran attendu (avec les mêmes valeurs) :

    ...
Bilan de la ronde : 1 alerte(s)

    ✏️ À toi de jouer : demandez d'abord combien de serveurs il faut visiter (nb = int(input("Combien de serveurs ? "))) et utilisez range(nb) au lieu de range(3). Bonus : affichez TOUT VA BIEN à la fin s'il n'y a aucune alerte (indice : if alertes == 0:).

    Validation

    La ronde fonctionne pour n'importe quel nombre de serveurs et le bilan compte juste les alertes. Testez avec 2 serveurs, puis 5.

Lexique

Vocabulaire
Mot Définition
variable Boîte étiquetée qui range une valeur (latence = 40)
input() Pose une question, la réponse est stockée dans une variable — toujours du texte !
int() Convertit du texte en nombre entier (indispensable après input())
str() Convertit un nombre en texte pour le coller avec +
if / elif / else Prendre une décision : « si… sinon si… sinon »
for / range() Répéter des instructions un nombre de fois connu
compteur Variable qui part de 0 et augmente de 1 (alertes = alertes + 1)
indentation Les 4 espaces qui marquent l'intérieur d'un if ou d'une boucle
