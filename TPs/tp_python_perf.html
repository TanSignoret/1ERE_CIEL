02

Introduction

Prérequis

Chez RéseauPro Solutions, les scripts doivent être :

  • Modulaires : chaque fonction a une responsabilité unique.
  • Réutilisables : une fonction peut être utilisée dans plusieurs scripts.
  • Robustes : le code gère les erreurs (ex: fichier introuvable, IP invalide).

Dans ce TP, vous allez :

  • Créer des fonctions pour valider des adresses IP, générer des mots de passe, ou analyser des logs.
  • Gérer les erreurs avec try/except.
  • Documenter vos fonctions avec des docstrings.
  • Versionner votre code avec Git.
Matériel nécessaire

Pour suivre ce TP, vous aurez besoin de :

  • Un poste informatique avec VS Code et les extensions Python et GitLens (installés en TP 2).
  • Un navigateur web (pour accéder à GitHub).
  • Ton dépôt GitHub BacPro_CIEL_Dev (créé en TP 2).
  • Un fichier de logs d'exemple (fourni par votre professeur ou à créer toi-même).

TP 3 — Créer des fonctions en Python

4 exercices

Dans ce TP, vous allez écrire 4 fonctions pour structurer tes scripts. Chaque fonction doit être testée, documentée, et versionnée dans votre dépôt GitHub.

  1. 1
    Valider une adresse IP

    Contexte : votre tuteur te demande de créer une fonction pour valider les adresses IP saisies par les utilisateurs.

    Consignes :

    • Créer une fonction valider_ip(ip) qui :
      • Retourne True si ip est au format xxx.xxx.xxx.xxx avec 0 ≤ xxx ≤ 255.
      • Retourne False sinon.
      • Gère les erreurs : Si ip n'est pas une chaîne de caractères, lève une exception avec raise ValueError("IP invalide").
    • Écrire un script qui :
      • Demande à l'utilisateur de saisir une IP.
      • Utilise la fonction valider_ip pour vérifier l'IP.
      • Affiche "IP valide" ou "IP invalide".
    • Documenter la fonction avec une docstring (ex: """Valide une adresse IP...""").
    Exemple

    Si l'utilisateur saisi 192.168.1.1, le script doit afficher :

    IP valide

    Si l'utilisateur saisi 256.1.1.1, le script doit afficher :

    IP invalide
    Validation

    Ta fonction valider_ip est testée, documentée, et le script fonctionne correctement.

  2. 2
    Générer un mot de passe

    Contexte : RéseauPro utilise des mots de passe robustes pour sécuriser ses systèmes. votre tuteur te demande de créer une fonction pour en générer.

    Consignes :

    • Créer une fonction generer_mot_de_passe(longueur=12) qui :
      • Génère un mot de passe aléatoire avec :
        • Majuscules (A-Z).
        • Minuscules (a-z).
        • Chiffres (0-9).
        • Symboles (!@#$%^&*).
      • Retourne le mot de passe généré.
      • Gère les erreurs : Si longueur < 8, lève une exception avec raise ValueError("Longueur minimale : 8").
    • Écrire un script qui :
      • Demande à l'utilisateur la longueur du mot de passe (par défaut : 12).
      • Utilise la fonction generer_mot_de_passe pour afficher un mot de passe.
    • Documenter la fonction avec une docstring.
    Exemple

    Si l'utilisateur saisi 8, le script peut afficher :

    Mot de passe généré : A1b@Cd#E
    Validation

    Ta fonction generer_mot_de_passe est testée, documentée, et génère des mots de passe valides.

  3. 3
    Analyser des logs

    Contexte : votre tuteur te demande d'analyser des logs réseau pour compter les erreurs et avertissements.

    Consignes :

    • Créer une fonction analyser_logs(fichier) qui :
      • Lit un fichier de logs (format : IP - Date - Niveau - Message).
      • Retourne un dictionnaire avec :
        • Le nombre total de lignes.
        • Le nombre de lignes par niveau (ERROR, WARNING, INFO).
      • Gère les erreurs : Si le fichier n'existe pas, affiche un message avec try/except FileNotFoundError.
    • Écrire un script qui :
      • Utilise la fonction analyser_logs sur un fichier logs.txt (fourni par votre professeur).
      • Affiche les résultats.
    • Documenter la fonction avec une docstring.
    Exemple de fichier logs.txt 
    192.168.1.1 - 2026-09-03 - ERROR - Connexion échouée
192.168.1.2 - 2026-09-03 - WARNING - Temps de réponse élevé
192.168.1.3 - 2026-09-03 - INFO - Connexion réussie
192.168.1.4 - 2026-09-03 - ERROR - Port fermé
    Exemple de sortie 
    {
    "total": 4,
    "niveaux": {
        "ERROR": 2,
        "WARNING": 1,
        "INFO": 1
    }
}
    Validation

    Ta fonction analyser_logs est testée, documentée, et gère les erreurs de fichier.

04

Lexique

Vocabulaire
Mot Définition
Fonction Bloc de code réutilisable, identifié par un nom, qui effectue une tâche spécifique.
Paramètre Variable passée à une fonction pour qu'elle puisse l'utiliser (ex: ip dans valider_ip(ip)).
Valeur de retour Valeur renvoyée par une fonction avec return (ex: True ou False).
Docstring Chaîne de caractères entre triple guillemets """ """ pour documenter une fonction.
Exception Erreur levée par le code (ex: ValueError, FileNotFoundError).
try/except Bloc utilisé pour gérer les erreurs : try exécute du code, except attrape les erreurs.
Refactoriser Améliorer la structure du code sans changer son fonctionnement (ex: utiliser des fonctions).
Commit Sauvegarde d'un état du code dans Git, avec un message descriptif.
