Exercice 1 — Calculer la moyenne de temps de réponse

4 exercices

Contexte : Votre tuteur vous demande de calculer la moyenne des temps de réponse de 5 serveurs (en ms).

Consignes :

  1. Demander à l'utilisateur de saisir 5 temps de réponse (un par un).
  2. Stocker chaque temps dans une variable distincte.
  3. Convertir les valeurs en nombres avec int().
  4. Calculer la somme et la moyenne.
  5. Afficher : Moyenne des temps de réponse : XX ms.

Exemple : Si l'utilisateur saisit 10, 20, 30, 40, 50, le script doit afficher :

Moyenne des temps de réponse : 30 ms
✅ Solution :
# Demander les 5 temps de réponse
temps1 = input("Saisis le temps de réponse 1 (ms) : ")
temps2 = input("Saisis le temps de réponse 2 (ms) : ")
temps3 = input("Saisis le temps de réponse 3 (ms) : ")
temps4 = input("Saisis le temps de réponse 4 (ms) : ")
temps5 = input("Saisis le temps de réponse 5 (ms) : ")

# Convertir les temps en nombres
temps1 = int(temps1)
temps2 = int(temps2)
temps3 = int(temps3)
temps4 = int(temps4)
temps5 = int(temps5)

# Calculer la somme et la moyenne
somme = temps1 + temps2 + temps3 + temps4 + temps5
moyenne = somme / 5

# Afficher le résultat
print("Moyenne des temps de réponse : " + str(moyenne) + " ms")
💡 Explications :

  • input() permet de demander une valeur à l'utilisateur. Le résultat est toujours un str.
  • int() convertit une chaîne de caractères en nombre entier pour permettre les calculs.
  • La moyenne est calculée en divisant la somme des valeurs par le nombre de valeurs (5).
  • str(moyenne) convertit la moyenne en chaîne de caractères pour l'affichage.

Exercice 2 — Vérifier un mot de passe

Conditions

Contexte : ProgPro impose des règles strictes pour les mots de passe : au moins 8 caractères.

Consignes :

  1. Demander à l'utilisateur de saisir un nom et un mot de passe.
  2. Vérifier si le mot de passe fait au moins 8 caractères avec len().
  3. Afficher :
    • Accès autorisé pour [nom] si le mot de passe est valide.
    • Accès refusé pour [nom] sinon.

Exemple : Si l'utilisateur saisit Alice et Pass123, le script doit afficher :

Accès autorisé pour Alice
✅ Solution :
# Demander le nom et le mot de passe
nom = input("Quel est ton nom ? ")
mot_de_passe = input("Quel est ton mot de passe ? ")

# Vérifier la longueur du mot de passe
if len(mot_de_passe) >= 8:
    print("Accès autorisé pour " + nom)
else:
    print("Accès refusé pour " + nom)
💡 Explications :

  • len(mot_de_passe) retourne le nombre de caractères dans le mot de passe.
  • La condition if len(mot_de_passe) >= 8: vérifie si le mot de passe fait au moins 8 caractères.
  • Si la condition est vraie, le message "Accès autorisé" est affiché. Sinon, c'est "Accès refusé".

Exercice 3 — Simuler un ping

Boucles

Contexte : Vous devez simuler un test de connectivité (ping) vers 10 adresses IP (192.168.1.1 à 192.168.1.10). On considère que le ping réussit si le dernier chiffre de l'IP est pair.

Consignes :

  1. Utiliser une boucle for pour parcourir les IP de 1 à 10.
  2. Pour chaque IP, afficher :
    • Ping réussi vers 192.168.1.[X] si X est pair.
    • Ping échoué vers 192.168.1.[X] si X est impair.

Exemple : Le script doit afficher :

Ping échoué vers 192.168.1.1
Ping réussi vers 192.168.1.2
...
Ping réussi vers 192.168.1.10
✅ Solution :
# Parcourir les IP de 1 à 10
for i in range(1, 11):
    if i % 2 == 0:
        print("Ping réussi vers 192.168.1." + str(i))
    else:
        print("Ping échoué vers 192.168.1." + str(i))
💡 Explications :

  • range(1, 11) génère les nombres de 1 à 10.
  • i % 2 == 0 vérifie si i est pair (le reste de la division par 2 est égal à 0).
  • Si la condition est vraie, le ping est réussi. Sinon, il est échoué.

Boucles et calculs
