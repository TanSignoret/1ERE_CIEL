Rappel des commandes Git

Ligne de commande

Voici les commandes Git essentielles pour ce TP :

git clone https://github.com/utilisateur/TP_CIEL_Git_Python_[Nom1]_[Nom2].git

Cloner un dépôt : Copie un dépôt distant en local.

git status

Voir l'état : Affiche les fichiers modifiés ou non suivis.

git add scripts_reseau.py

Ajouter un fichier : Ajoute un fichier à l'index (staging area).

git add .

Ajouter tous les fichiers : Ajoute tous les fichiers modifiés/nouveaux à l'index.

git commit -m "Ajout des exercices"

Faire un commit : Valide les modifications avec un message.

git push

Pousser sur GitHub : Envoie les commits locaux vers GitHub.

git pull

Récupérer les modifications : Récupère les dernières modifications du dépôt distant.

Exercice 1 — Manipulation de variables

Variables

Consignes :

  • Créer deux variables ip1 et ip2 avec les valeurs "192.168.1.1" et "10.0.0.1".
  • Échanger leurs valeurs (pour que ip1 contienne "10.0.0.1" et ip2 contienne "192.168.1.1").
  • Afficher les valeurs finales de ip1 et ip2 avec print().

Exemple :

Avant échange : ip1 = 192.168.1.1, ip2 = 10.0.0.1
Après échange : ip1 = 10.0.0.1, ip2 = 192.168.1.1
✅ Solution :
# Déclarer les variables
ip1 = "192.168.1.1"
ip2 = "10.0.0.1"

# Afficher les valeurs avant échange
print("Avant échange : ip1 = " + ip1 + ", ip2 = " + ip2)

# Échanger les valeurs
tmp = ip1
ip1 = ip2
ip2 = ip1

# Afficher les valeurs après échange
print("Après échange : ip1 = " + ip1 + ", ip2 = " + ip2)
💡 Explications :

  • On utilise une variable temporaire tmp pour stocker temporairement la valeur de ip1.

Exercice 2 — Calcul de somme et moyenne

Calculs

Consignes :

  • Demander à l'utilisateur de saisir deux nombres entiers (un par un) avec input().
  • Stocker ces nombres dans deux variables : nombre1 et nombre2.
  • Calculer la somme et la moyenne de ces deux nombres.
  • Afficher les résultats sous la forme : 
    La somme de [nombre1] et [nombre2] est [somme].
La moyenne de [nombre1] et [nombre2] est [moyenne].
✅ Solution :
# Demander les deux nombres
nombre1 = input("Saisis le premier nombre : ")
nombre2 = input("Saisis le deuxième nombre : ")

# Convertir en nombres
nombre1 = int(nombre1)
nombre2 = int(nombre2)

# Calculer la somme et la moyenne
somme = nombre1 + nombre2
moyenne = somme / 2

# Afficher les résultats
print("La somme de " + str(nombre1) + " et " + str(nombre2) + " est " + str(somme) + ".")
print("La moyenne de " + str(nombre1) + " et " + str(nombre2) + " est " + str(moyenne) + ".")
💡 Explications :

  • input() retourne toujours un str, donc il faut utiliser int() pour convertir les entrées en nombres.
  • La somme est calculée avec nombre1 + nombre2.
  • La moyenne est calculée en divisant la somme par 2.
  • str() est utilisé pour convertir les nombres en chaînes de caractères pour l'affichage.

Exercice 3 — Message de bienvenue

Entrées/Sorties

Consignes :

  • Demander à l'utilisateur de saisir son nom et son prénom.
  • Afficher un message de bienvenue sous la forme : 
    Bonjour, [prénom] [nom] !

Exemple :

>> Quel est ton nom ? Jolly
>> Quel est ton prénom ? Thomas
Bonjour, Thomas Jolly !
✅ Solution :
# Demander le nom et le prénom
nom = input("Quel est ton nom ? ")
prenom = input("Quel est ton prénom ? ")

# Afficher le message de bienvenue
print("Bonjour, " + prenom + " " + nom + " !")
💡 Explications :

  • input() est utilisé pour demander le nom et le prénom.
  • Les variables nom et prenom sont concaténées avec + pour former le message final.
  • Un espace " " est ajouté entre prenom et nom pour séparer les deux.

Exercice 4 — Vérifier l'âge

Conditions

Consignes :

  • Demander à l'utilisateur de saisir son âge (en tant que str).
  • Le convertir en int.
  • Afficher :
    • "Accès autorisé." si l'âge est supérieur ou égal à 18.
    • "Accès refusé." sinon.
✅ Solution :
# Demander l'âge
age = input("Quel est ton âge ? ")

# Convertir en nombre
age = int(age)

# Vérifier l'âge
if age >= 18:
    print("Accès autorisé.")
else:
    print("Accès refusé.")
💡 Explications :

  • input() retourne un str, donc il faut utiliser int() pour convertir l'âge en nombre.
  • La condition if age >= 18: vérifie si l'âge est supérieur ou égal à 18.
  • Si la condition est vraie, "Accès autorisé." est affiché. Sinon, c'est "Accès refusé.".

Exercice 5 — Vérifier la longueur du mot de passe

Conditions

Consignes :

  • Demander à l'utilisateur de saisir un mot de passe.
  • Afficher :
    • "Mot de passe valide." si le mot de passe contient au moins 8 caractères.
    • "Mot de passe invalide." sinon.

Utilisez len() pour vérifier la longueur.

✅ Solution :
# Demander le mot de passe
mot_de_passe = input("Saisis un mot de passe : ")

# Vérifier la longueur
if len(mot_de_passe) >= 8:
    print("Mot de passe valide.")
else:
    print("Mot de passe invalide.")
💡 Explications :

  • len(mot_de_passe) retourne le nombre de caractères dans le mot de passe.
  • La condition if len(mot_de_passe) >= 8: vérifie si le mot de passe fait au moins 8 caractères.

Exercice 6 — Afficher les 10 premiers nombres pairs

Boucles

Consignes :

  • Utiliser une boucle for pour afficher les 10 premiers nombres pairs (de 0 à 18).
✅ Solution :
# Afficher les 10 premiers nombres pairs (0 à 18)
# option 1
for i in range(0, 20, 2):
    print(i)

# option 2
for i in range(0, 20):
    if i % 2 == 0:
        print(i)
💡 Explications :

  • range(0, 20, 2) génère les nombres de 0 à 18 avec un pas de 2 (0, 2, 4, ..., 18).
  • La boucle for parcourt chaque nombre généré et l'affiche avec print().
  • i % 2 == 0 vérifie si i est pair (le reste de la division par 2 est égal à 0).

Exercice 7 — Afficher la table de multiplication

Boucles

Consignes :

  • Demander à l'utilisateur de saisir un nombre (en tant que str).
  • Le convertir en int.
  • Afficher la table de multiplication de ce nombre (de 1 à 10) avec une boucle for.

Exemple : Si l'utilisateur saisi 5, le script doit afficher :

Table de 5 :
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
✅ Solution :
# Demander le nombre
nombre = input("Saisis un nombre : ")
nombre = int(nombre)

# Afficher la table de multiplication
print("Table de " + str(nombre) + " :")
for i in range(1, 11):
    resultat = nombre * i
    print(str(nombre) + " x " + str(i) + " = " + str(resultat))
💡 Explications :

  • range(1, 11) génère les nombres de 1 à 10.
  • À chaque itération, resultat = nombre * i calcule le produit.
  • Le résultat est affiché sous la forme "5 x 1 = 5" avec + pour concaténer.
