Exercice 1 — Gestion des variables et entrée/sortie

Variables

Contexte : Votre tuteur vous demande de créer un script pour enregistrer les informations d'un nouveau serveur.

Consignes :

  • Demander à l'utilisateur de saisir :
    • Le nom du serveur (ex: "SRV-WEB-01").
    • L'adresse IP du serveur (ex: "192.168.1.1").
    • Le nombre de ports ouverts (ex: 3).
  • Afficher un message de confirmation avec les informations saisies : 
    Le serveur [nom] a pour adresse IP [IP] et a [ports] ports ouverts.

Exemple : Si l'utilisateur saisit SRV-WEB-01, 192.168.1.1 et 3, le script doit afficher :

Le serveur SRV-WEB-01 a pour adresse IP 192.168.1.1 et a 3 ports ouverts.
✅ Solution :
# Demander les informations du serveur
nom_serveur = input("Quel est le nom du serveur ? ")
adresse_ip = input("Quel est l'adresse IP du serveur ? ")
ports_ouverts = input("Combien de ports sont ouverts ? ")

# Afficher le message de confirmation
print("Le serveur " + nom_serveur + " a pour adresse IP " + adresse_ip + " et a " + ports_ouverts + " ports ouverts.")
💡 Explications :

  • Chaque information est demandée avec input() et stockée dans une variable.
  • Le message final est construit avec + pour additionner le contenu des variables.
  • Les variables sont de type str (chaîne de caractères), car input() retourne toujours un str.

Exercice 2 — Vérification de configuration avec conditions

Conditions

Contexte : RéseauPro impose des règles pour les mots de passe des serveurs.

Consignes :

  • Demander à l'utilisateur de saisir un nom et un mot de passe pour créer un compte. Stocker ces informations dans 2 variables.
  • Demander à l'utilisateur de saisir à nouveau un nom et un mot de passe pour se connecter.
  • Vérifier si :
    • Le nom saisi correspond au nom enregistré.
    • Le mot de passe saisi correspond au mot de passe enregistré.
  • Afficher :
    • "Connexion effectuée" si le nom et le mot de passe correspondent.
    • "Nom incorrect" si seul le nom est incorrect.
    • "Mot de passe incorrect" si seul le mot de passe est incorrect.
    • "Connexion impossible." sinon.

Exemple :

  • Si l'utilisateur enregistre Alice et Pass123, puis saisit Alice et Pass123 → Connexion effectuée.
  • Si l'utilisateur saisit Bob et Pass123 → Nom incorrect.
✅ Solution :
# Enregistrer un compte
nom_enregistre = input("Saisis un nom pour t'enregistrer : ")
mot_de_passe_enregistre = input("Saisis un mot de passe pour t'enregistrer : ")

# Demander les informations de connexion
nom_saisi = input("Saisis ton nom pour te connecter : ")
mot_de_passe_saisi = input("Saisis ton mot de passe pour te connecter : ")

# Vérifier les informations
if nom_saisi == nom_enregistre and mot_de_passe_saisi == mot_de_passe_enregistre:
    print("Connexion effectuée")
elif nom_saisi != nom_enregistre and mot_de_passe_saisi == mot_de_passe_enregistre:
    print("Nom incorrect")
elif nom_saisi == nom_enregistre and mot_de_passe_saisi != mot_de_passe_enregistre:
    print("Mot de passe incorrect")
else:
    print("Connexion impossible.")
💡 Explications :

  • Les informations enregistrées et saisies sont comparées avec ==.
  • La structure if/elif/else permet de vérifier plusieurs conditions dans l'ordre.
  • Chaque elif vérifie un cas spécifique (nom incorrect ou mot de passe incorrect).
  • Le else est exécuté si aucune des conditions précédentes n'est vraie.

Exercice 3 — Simuler un scan de ports avec une boucle for

Boucles

Contexte : Votre tuteur vous demande de simuler un scan des ports 22, 80 et 443 sur un serveur.

Consignes :

  • Utiliser une boucle for pour parcourir les ports 22, 80 et 443.
  • Pour chaque port, afficher : 
    Scanne le port [port]...

Exemple : Le script doit afficher :

Scanne le port 22...
Scanne le port 80...
Scanne le port 443...
✅ Solution :
# Liste des ports à scanner
ports = [22, 80, 443]

# Parcourir les ports
for port in ports:
    print("Scanne le port " + str(port) + "...")
💡 Explications :

  • La liste ports contient les trois ports à scanner : 22, 80 et 443.
  • La boucle for port in ports: parcourt chaque élément de la liste.
  • À chaque itération, la variable port prend la valeur du prochain élément de la liste.
  • str(port) convertit le nombre en chaîne de caractères pour l'affichage.

Exercice 4 — Vérification de connexion avec une boucle while

Boucles

Contexte : Votre tuteur vous demande de créer un script qui demande à l'utilisateur de saisir un code de connexion valide.

Consignes :

  • Le code de connexion valide est "CIEL2026".
  • Utiliser une boucle while pour demander à l'utilisateur de saisir un code jusqu'à ce qu'il soit valide.
  • Si le code est incorrect, afficher : 
    Code incorrect. Réessayez.
  • Si le code est correct, afficher : 
    Accès autorisé.

Exemple : Si l'utilisateur saisi "ABC123", puis "CIEL2026", le script doit afficher :

Code incorrect. Réessayez.
Accès autorisé.
✅ Solution :
# Code de connexion valide
code_valide = "CIEL2026"

# Demander le code à l'utilisateur
code_saisi = input("Saisis le code de connexion : ")

# Vérifier le code
while code_saisi != code_valide:
    print("Code incorrect. Réessayez.")
    code_saisi = input("Saisis le code de connexion : ")

# Si le code est correct
print("Accès autorisé.")
💡 Explications :

  • La boucle while code_saisi != code_valide: continue tant que le code saisi est différent du code valide.
  • À chaque itération, le message "Code incorrect. Réessayez." est affiché.
  • L'utilisateur est invité à saisir un nouveau code avec input().
  • Dès que le code est correct, la boucle s'arrête et le message "Accès autorisé." est affiché.

Exercice 5 — Gestion d'une liste d'adresses IP

Listes

Contexte : Votre tuteur vous demande de gérer une liste d'adresses IP pour un réseau local.

Consignes :

  • Créer une liste avec les adresses IP suivantes : ["192.168.1.1", "192.168.1.2", "192.168.1.3"].
  • Afficher la deuxième adresse IP de la liste (index 1).
  • Ajouter une quatrième adresse IP ("192.168.1.4") à la liste.
  • Afficher toute la liste mise à jour.

Exemple : Le script doit afficher :

Deuxième adresse IP : 192.168.1.2
Liste complète : ['192.168.1.1', '192.168.1.2', '192.168.1.3', '192.168.1.4']
✅ Solution :
# Créer la liste d'adresses IP
ips = ["192.168.1.1", "192.168.1.2", "192.168.1.3"]

# Afficher la deuxième adresse IP (index 1)
print("Deuxième adresse IP : " + ips[1])

# Ajouter une quatrième adresse IP
ips.append("192.168.1.4")

# Afficher toute la liste
print("Liste complète : " + str(ips))
💡 Explications :

  • La liste ips est créée avec les trois adresses IP initiales.
  • ips[1] accède à la deuxième adresse IP (l'index commence à 0).
  • ips.append("192.168.1.4") ajoute une nouvelle adresse à la fin de la liste.
  • str(ips) convertit la liste en chaîne de caractères pour l'affichage.
